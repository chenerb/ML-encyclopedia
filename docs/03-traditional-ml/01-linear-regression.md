# 线性回归：机器学习的第一课

## 概述

> **悬念提问**：一条普普通通的直线，凭什么能预测房价、股价，甚至一个人的寿命？它既不会思考，也没有"智能"，却成了几乎所有机器学习算法共同的"第一课"。这背后到底藏着什么魔法？

线性回归（Linear Regression）是机器学习中最简单、最古老，也最基础的算法。它的目标极其朴素：**找到一条直线（或平面），让预测值尽量贴近真实值**。

别小看这条直线——它是无数复杂模型（神经网络、深度学习）的地基。理解了它，你就拿到了通往机器学习世界的钥匙。

---

## 历史背景

### "回归"一词的浪漫起源

1886 年，英国统计学家**弗朗西斯·高尔顿**（Francis Galton，达尔文的表弟）在研究遗传学时发现了一个有趣的现象：

> 高个子父母的子女，平均身高虽然高于常人，但往往**比父母更接近平均水平**；矮个子父母的子女，平均身高也**向平均水平"靠拢"**。

他称这种现象为 **"回归到平庸"（regression to mediocrity）**。这就是"回归"一词的由来——它最初描述的是一种**向均值回归的趋势**，如今则泛指"用自变量预测因变量"的一类方法。

### 最小二乘法：两位天才的"公案"

线性回归的数学核心是**最小二乘法**（Least Squares）：

- **1805 年**：法国数学家**勒让德**（Legendre）首次公开发表最小二乘法
- **1809 年**：德国"数学王子"**高斯**（Gauss）声称自己早就用过了，并给出了严格的统计学证明，引发了一场关于优先权的著名争论

这场争论没有输家——今天我们记住的是：**最小二乘法让"找最佳直线"有了明确、可计算的标准**。

> 🧠 **费曼自问**：如果把"回归"讲给朋友听，你会怎么说？——"回归"最初的意思是"事物会向平均水平靠拢"，后来被借用来表示"用已知数据去预测未知数值"。

## 核心原理

### 1. 假设：数据背后是一条直线

线性回归假设目标值 y 与特征 x 之间存在**线性关系**：

**一元线性回归（一个特征）：**

```
y = w·x + b
```

- `w`：斜率（权重），表示 x 每变化一单位，y 变化多少
- `b`：截距（偏置），表示 x = 0 时的基准值

**多元线性回归（多个特征）：**

```
y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
```

用矩阵形式简洁地写（这也是你在代码里看到的样子）：

```
ŷ = Xw + b
```

其中 `X` 是样本矩阵，`w` 是权重向量，`ŷ` 是预测值。

> **示例**：预测房价
> ```
> 房价 = 1.5万 × 面积 + (-0.3万) × 房龄 + 50万(基准)
> ```
> 面积每多 1㎡，房价涨 1.5 万；房龄每多 1 年，房价跌 0.3 万。

### 2. 损失函数：如何衡量"画得准不准"

一条直线画得好不好，需要一个**打分标准**。最常用的是**均方误差**（Mean Squared Error, MSE）：

```
MSE = (1/n) × Σ (yᵢ - ŷᵢ)²
```

也就是：**所有样本"预测值与真实值之差的平方"的平均值**。

> 🧠 **费曼自问**：为什么是"平方"，而不是直接把误差相加？
>
> 因为误差有正有负，直接相加会**互相抵消**——"高估 10 万"和"低估 10 万"加起来是 0，看起来像"没误差"。平方之后所有误差都变成正数，而且**误差越大，惩罚越重**（10 的平方是 100，远大于 1 的平方）。这就是"最小**二**乘"中"二"的含义。

### 3. 求解：怎么找到"最好的那根线"

有两种主流方法：

#### 方法一：解析解（最小二乘法，一步到位）

对于线性回归，存在一个**闭式公式**，可以直接算出最优权重：

```
w = (XᵀX)⁻¹ Xᵀy
```

这个公式一步到位、精确无比，但当特征很多时（`XᵀX` 求逆非常昂贵）就不实用了。

#### 方法二：梯度下降（迭代逼近）

像"盲人下山"一样，从随机位置出发，每次朝"误差下降最快"的方向挪一小步，反复迭代直到误差最小。详细原理见 [梯度下降](../04-neural-networks/04-gradient-descent.md)。

> **提示**：实践中，特征少用解析解（scikit-learn 的 `LinearRegression`），特征多或数据量大时用梯度下降（`SGDRegressor`）。

## 通俗解释

### 线性回归就是"用直尺找规律"

想象你在方格纸上画散点图：横轴是"学习时间"，纵轴是"考试成绩"。每个学生是一个点。

你发现这些点大致排成一条**从左下到右上的斜线**——学得越久，分数越高。

线性回归做的事就是：**找一把直尺，放在这些点中间，让所有点离这把尺子的总距离最小**。有了这把尺子，你就能预测："如果某人学了 5 小时，他大概能考多少分？"

> 关键洞察：线性回归不是在"记住"每个学生的成绩，而是在**提炼一条规律**——"分数 ≈ 学习时间 × 某个斜率 + 基础分"。

## 📖 寓言故事：中介小李的"定价秘籍"

刚入行的房产中介小李，总是报错房价：报价高了，客户扭头就走；报价低了，房东拍桌子骂人。三个月只成交了一单，眼看就要被辞退。

绝望的小李翻出公司过去十年的成交记录，摊在桌上研究到深夜。突然，他眼睛一亮——这些房子的价格，好像都和一个东西紧紧绑在一起：**面积**。

他找来一张大纸，横轴标"面积"，纵轴标"成交价"，把每一套房画成一个点。神奇的事发生了：这些点**大致排成一条斜线**！

"面积每多一平米，房价就涨大约一万五！"小李兴奋地拿起直尺，放在这些点中间，反复挪动，直到"所有点离这条线的距离之和"看起来最小。

从此，小李报价前只需看一眼面积，往他的"神尺"上一比，价格八九不离十。客户惊叹："你怎么算得这么准？"

小李微微一笑，没有告诉他——自己手里那把"尺子"，就是传说中的**线性回归**。

> **寓意**：线性回归不是死记每套房的价格，而是从数据中**提炼出一条规律**（一条直线），用它来预测新情况。那条"离所有点最近的直线"，就是最小二乘法的杰作。

## 算法步骤

1. **收集数据**：准备特征矩阵 X 和目标值 y
2. **选择模型**：假设 y 与 X 呈线性关系，`ŷ = Xw + b`
3. **定义损失**：用 MSE 衡量预测误差
4. **求解参数**：用解析解 `w = (XᵀX)⁻¹Xᵀy` 或梯度下降找到使损失最小的 w、b
5. **评估模型**：用测试集计算 R²、RMSE 等指标
6. **做出预测**：输入新样本的特征，输出预测值

## 优缺点分析

### 优点

- **简单可解释**：每个权重直接告诉你"特征每变化一单位，结果变多少"，不像深度学习那样是黑盒
- **训练极快**：解析解一步到位，万级数据毫秒出结果
- **不易过拟合**：模型简单，泛化能力往往不错
- **是无数算法的地基**：逻辑回归、神经网络、岭回归都建立在它之上

### 缺点

- **只能拟合线性关系**：数据是曲线（如抛物线）时表现差
- **对异常值敏感**：一个极端离群点能大幅"拉偏"整条直线
- **假设较强**：要求误差独立、同方差、服从正态分布，现实中常不满足
- **多重共线性**：特征之间高度相关时，权重估计会不稳定

## 应用场景

- **房价预测**：面积、地段、房龄 → 价格
- **销售预测**：广告投入、季节、价格 → 销量
- **医学指标**：年龄、体重、血压 → 某种疾病风险评分
- **金融分析**：宏观指标 → 股票收益率（谨慎！金融数据常不满足线性假设）
- **基准模型**：任何回归任务先用线性回归跑一个 baseline

---

## 实践建议

- **先画散点图**：动手建模前，先可视化看数据是否真的呈线性，别盲目套用
- **特征标准化**：特征量纲差异大时（如"收入"和"年龄"），先标准化再做梯度下降，收敛更快
- **处理异常值**：用箱线图找离群点，必要时剔除或使用更稳健的损失
- **看 R² 而非只看 MSE**：MSE 受量纲影响，R²（决定系数）能告诉你"模型解释了数据多少比例的方差"

> **警告**：R² 高不代表模型一定好！给模型加一堆无用特征，R² 也会虚高（调整 R² 可缓解）。更别用线性回归去预测有明显周期或突变的序列。

## 总结

**关键要点：**
1. 线性回归 = 找到一条"离所有数据点最近"的直线来预测
2. 核心是**最小二乘法**：让误差的平方和最小
3. 求解有两条路：解析解（一步到位）和梯度下降（迭代逼近）
4. 简单可解释，是全部机器学习的地基，但只能拟合线性关系
