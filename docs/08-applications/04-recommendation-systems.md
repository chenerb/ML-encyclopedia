# 推荐系统：比你更懂你的"猜心术"

## 概述

> **悬念提问**：打开短视频 App，一刷就停不下来；打开购物 App，首页全是你想买的东西。它怎么知道你此刻想看什么？这背后，是推荐系统——一门"猜你喜欢"的技术，也是互联网公司最赚钱的 AI 应用之一。

推荐系统（Recommendation System）根据用户的历史行为和偏好，预测用户可能感兴趣的内容。它是电商、短视频、音乐、资讯平台的核心引擎。

---

## 核心方法

### 1. 协同过滤（Collaborative Filtering）

**"物以类聚，人以群分"**：

- **基于用户**：找和你口味相似的人，推荐他们喜欢的
- **基于物品**：找和你喜欢过的物品相似的物品

```
你喜欢《三体》，另一个也喜欢《三体》的人还喜欢《流浪地球》
→ 推荐你《流浪地球》
```

### 2. 内容推荐（Content-based）

根据物品本身的特征匹配：

```
你爱看科幻电影 → 分析《流浪地球》标签是"科幻" → 推荐给你
```

### 3. 混合推荐

协同过滤 + 内容推荐 + 规则，取长补短。

### 4. 深度学习推荐

- **双塔模型**：用户塔 + 物品塔，算相似度
- **序列推荐**：用 RNN/Transformer 建模用户行为序列
- **召回 + 排序**：先粗筛（召回），再精排（排序）

### 5. 冷启动问题

新用户/新物品没有历史数据，怎么办？

- 新用户：用人口属性、引导选择兴趣
- 新物品：用内容特征、热门推荐

---

## 核心流程

```
召回（从百万候选中筛出几百个）→ 排序（精排打分）→ 重排（多样性、去重）→ 展示
```

## 📖 寓言故事：书店老板的"猜心术"

老街有家书店，老板记性极好。他有个本子，记着每个顾客买过什么书。

新顾客进门，老板的"猜心术"开始施展：

- 你买了《三体》，他翻本子一查——**买《三体》的人，大多也买了《球状闪电》**（物品协同过滤），于是推荐给你
- 发现你总在"科幻"区转悠，他**按"科幻"这个标签**给你推新书（内容推荐）
- 你若是生面孔（冷启动），他就先问问你爱看什么类型，再推荐

久而久之，顾客都说："这老板比我还懂我想看什么。"

老板笑："我哪懂什么读心术？不过是**记住'谁和谁口味像'、'什么书和什么书相关'**。把千万人的选择聚在一起，就成了一面能照出你喜好的镜子。"

> **寓意**：推荐系统的核心是**协同过滤（找相似的人/物品）+ 内容匹配**，本质是"用群体的选择，照见个体的偏好"。深度学习让"猜你喜欢"越来越准。

---

## 挑战与趋势

- **冷启动**：新用户/新物品
- **信息茧房**：过度个性化导致视野窄化
- **多样性 vs 准确性**：既要准，又不能太"窄"
- **实时性**：行为即时反馈
- **可解释性**：为什么推荐这个（"猜你喜欢"的理由）

## 总结

**关键要点：**
1. 推荐系统 = 猜用户喜欢什么
2. 核心：协同过滤 + 内容推荐 + 混合
3. 深度学习（双塔、序列）提升效果
4. 流程：召回 → 排序 → 重排
5. 挑战：冷启动、信息茧房、多样性
