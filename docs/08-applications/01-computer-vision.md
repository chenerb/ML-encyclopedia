# 计算机视觉：让机器"看见"世界

## 概述

> **悬念提问**：人眼看到一张图，瞬间理解"这是猫、它在桌上、窗外在下雨"。让机器做到同样的事，人类走了整整六十年。这门"让机器看见"的技术，就是计算机视觉。

计算机视觉（Computer Vision, CV）是让机器从图像和视频中**理解世界**的技术。它是深度学习最成熟、应用最广的领域之一，也是 CNN 的主战场。

---

## 核心任务

### 1. 图像分类（Classification）

判断整张图"是什么"。

```
输入：一张图 → 输出："猫"（概率 92%）
```

- 代表：ImageNet、ResNet
- 应用：相册归类、质检分拣

### 2. 目标检测（Detection）

找出图中物体并框出位置。

```
输入：一张街景 → 输出：[车(x,y,w,h), 行人(x,y,w,h), 红绿灯(...)]
```

- 代表：YOLO、Faster R-CNN
- 应用：自动驾驶、安防监控

### 3. 图像分割（Segmentation）

像素级分类，把每个像素归类。

- **语义分割**：区分类别（道路 vs 行人）
- **实例分割**：区分个体（这辆车 vs 那辆车）
- 应用：医学影像、自动驾驶可行驶区域

### 4. 人脸识别（Face Recognition）

检测人脸 → 提取特征 → 比对身份。

- 代表：FaceNet、ArcFace
- 应用：手机解锁、门禁、支付

### 5. 图像生成与增强

- 超分辨率：模糊变清晰
- 风格迁移：照片变油画
- 文生图：文字生成图像（扩散模型）

## 📖 寓言故事：复明的人

一个天生失明的人，经神医妙手，突然复明了。

可他睁开眼，却"看不见"——眼前是一堆颜色和光影，他分不清哪个是桌子、哪个是门、哪个是人。因为"看见"不只是**收到光**，更是**理解光里的含义**。

神医教他：

- 先认"这是什么"（分类）：圆的是苹果，方的是门
- 再认"在哪"（检测）：苹果在桌上，门在墙边
- 再认"边界"（分割）：桌子的边缘到哪、人和背景的分界在哪
- 最后认"是谁"（人脸识别）：这张脸是老朋友，那张脸是陌生人

日复一日，他终于真正"看见"了世界。

他感慨："原来'看'这件事，分这么多层。**收到图像只是第一步，理解图像才是真本事。**"

> **寓意**：计算机视觉就是教机器"理解图像"——**分类（是什么）、检测（在哪）、分割（边界）、识别（是谁）**，层层递进。收到像素只是开始，理解含义才是目标。

## 挑战与趋势

- **小样本**：从少样本学习
- **3D 视觉**：从平面到立体
- **视频理解**：从静态到动态
- **多模态**：图文音统一理解
- **落地效率**：边缘设备实时运行

## 总结

**关键要点：**
1. 计算机视觉 = 让机器理解图像和视频
2. 核心任务：分类、检测、分割、识别、生成
3. CNN 是主力，Transformer/ViT 正在崛起
4. 从"收到像素"到"理解含义"是本质
