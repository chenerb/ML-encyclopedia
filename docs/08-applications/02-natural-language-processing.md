# 自然语言处理：让机器"读懂"人类语言

## 概述

> **悬念提问**："我能理解你的每一句话"——这是人类独有的能力，如今机器正在快速逼近。让机器看懂文字、听懂人话、甚至开口说话，这门技术就是自然语言处理（NLP）。

自然语言处理（Natural Language Processing, NLP）是让机器理解、生成、处理人类语言的技术。它是 Transformer 的主战场，也是大模型（GPT、BERT）的核心应用领域。

---

## 核心任务

### 1. 文本分类（Text Classification）

判断文本的类别或情感：

```
"这部电影太棒了！" → 情感：正面
"您的包裹已发货" → 类别：物流通知
```

- 应用：垃圾邮件过滤、情感分析、舆情监控

### 2. 命名实体识别（NER）

从文本中抽取实体：

```
"乔布斯 2007 年在 旧金山 发布 iPhone"
→ 人名：乔布斯；时间：2007；地点：旧金山；产品：iPhone
```

### 3. 机器翻译（Machine Translation）

源语言 → 目标语言：

- 代表：Google 翻译、Transformer
- 从统计方法进化到神经网络，再到 Transformer

### 4. 文本生成（Text Generation）

自动写文章、写代码、写诗：

- 代表：GPT 系列
- 应用：写作辅助、代码补全、对话系统

### 5. 问答与对话（QA & Dialogue）

- 问答：从文本中找答案
- 对话：ChatGPT 式的多轮交流

### 6. 文本摘要（Summarization）

长文 → 短摘要：

- 抽取式：从原文挑句子
- 生成式：用自己的话概括

```
规则/统计时代 → RNN/LSTM → Transformer → 预训练大模型（BERT/GPT）
  n-gram/HMM     Seq2Seq     Attention     LLM
```

## 📖 寓言故事：破译天书的人

考古学家发现了一卷"天书"，上面的文字无人能识。

甲学者用**死办法**：翻遍词典，一个字一个字硬对应（规则/统计方法），结果语法不通、语义混乱。

乙学者却换了个思路：

1. 他先**大量阅读**这种文字的所有文献（预训练），慢慢摸清"什么样的字常和什么样的字一起出现"
2. 遇到生词，他**看前后文猜**（上下文理解，像 BERT 的完形填空）
3. 要翻译时，他**读懂整句再转述**（编码-解码，像 Transformer）
4. 还能**接着上文往下写**（生成，像 GPT）

乙学者破译了天书，还发现天书记载的竟是一段失传的文明。

有人问诀窍。乙学者说："语言不是'字和字的死对应'，而是**上下文里的活意思**。你得让机器学会'看前后、猜中间、懂整体'。"

> **寓意**：NLP 的核心是让机器理解"上下文里的意思"——**预训练学规律、双向看上下文、编码-解码翻译、自回归生成**。Transformer 和大模型正是沿着这条路走通的。

## 挑战与趋势

- **多语言**：低资源语言的翻译
- **多模态**：图文、音视频统一理解
- **推理能力**：从"会说话"到"会思考"
- **幻觉问题**：大模型"一本正经胡说八道"的治理
- **可控生成**：安全、合规的内容生成
