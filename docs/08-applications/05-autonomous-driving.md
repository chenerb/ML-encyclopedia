# 自动驾驶：AI 当司机

## 概述

> **悬念提问**：一辆车在川流不息的马路上，要实时看清行人、车辆、红绿灯，还要瞬间做出刹车、变道、避让的决策——这一切，都交给 AI。自动驾驶，是深度学习最惊心动魄的"考场"。

自动驾驶（Autonomous Driving）是让汽车在无人干预下感知环境、规划路径、控制行驶的技术。它融合了计算机视觉、传感器融合、决策规划，是 AI 的集大成应用。

---

## 核心技术

### 1. 感知（Perception）：看见世界

用传感器"看清"周围：

- **摄像头**：识别车道线、交通标志、行人（CNN）
- **激光雷达（LiDAR）**：精确测距、3D 建模
- **毫米波雷达**：测速、抗恶劣天气

**目标检测**是核心：实时框出车辆、行人、障碍物（YOLO 等）。

### 2. 决策与规划（Planning）：想好怎么走

- **路径规划**：从 A 到 B 的全局路线
- **行为决策**：何时变道、何时超车、何时让行
- **轨迹规划**：生成一条平滑、安全的具体行驶轨迹

### 3. 控制（Control）：执行动作

把规划好的轨迹转成油门、刹车、方向盘的指令。

### 4. 端到端 vs 模块化

```
模块化：感知 → 决策 → 控制（各模块独立，可解释、可调试）
端到端：图像 → 一个神经网络 → 驾驶指令（黑盒、难调试）
```

## 自动驾驶分级（SAE）

| 级别 | 名称 | 说明 |
|------|------|------|
| L0 | 无自动化 | 人全权驾驶 |
| L1-L2 | 辅助驾驶 | 自适应巡航、车道保持，人随时接管 |
| L3 | 有条件自动化 | 特定场景车自己开，人备勤 |
| L4 | 高度自动化 | 限定区域无人驾驶 |
| L5 | 完全自动化 | 任何场景无人驾驶 |

---

## 核心挑战

- **安全**：一次失误可能就是生命代价
- **长尾场景**：罕见但致命的边缘情况（突然窜出的动物、翻倒的货车）
- **恶劣天气**：雨雪雾降低传感器可靠性
- **实时性**：毫秒级决策
- **责任归属**：事故算谁的？（伦理与法律）

## 📖 寓言故事：马车夫的老练

老马车夫赶了四十年车，从没出过事。新来的年轻车夫不服："不就是看路、挥鞭吗？"

可一上路，差别就出来了：

- 路口突然窜出个孩子，老车夫**早早就减速**了——他"感知"到前方路口可能有情况
- 遇到窄路会车，老车夫**提前规划**了错车的位置
- 雨夜路滑，老车夫**放慢速度、轻拉缰绳**（控制要稳）

年轻车夫问："你怎么总能预判危险？"

老车夫说："赶车不是'看见才反应'，而是**看（感知）、想（决策）、做（控制）三步一气呵成**。更要紧的是——**见过千千万万种'意外'（长尾场景）**，才能在意外来临时不慌。"

"自动驾驶也是一个道理：**看得清、想得对、控得稳，还得见过足够多的'意外'。**"

> **寓意**：自动驾驶 = **感知（看）+ 决策（想）+ 控制（做）** 三步闭环。它最大的挑战不是"正常路况"，而是那些罕见却致命的"长尾场景"——正如老车夫靠的是四十年见过的种种意外。

## 总结

**关键要点：**
1. 自动驾驶 = 感知 + 决策 + 控制
2. 多传感器融合（摄像头、LiDAR、雷达）
3. 分级 L0-L5，当前量产多在 L2-L3
4. 核心挑战：安全、长尾场景、实时性
