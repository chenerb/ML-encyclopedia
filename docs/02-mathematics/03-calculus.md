# 微积分基础

## 概述

微积分是研究**变化**的数学。在机器学习中，我们最关心的是：**如何调整模型参数，让预测更准确？** 这个问题的答案就在微积分中。

本篇文章将聚焦微积分在机器学习中的应用，特别是**梯度**这个概念——它是所有优化算法的核心。

---

## 为什么机器学习需要微积分？

> **核心问题**：模型有误差，如何调整参数减少误差？

以线性回归为例：
```
误差 = (真实值 - 预测值)²
预测值 = w₁x₁ + w₂x₂ + b
```

我们想知道：
- 如果增加w₁一点，误差会怎么变？（导数）
- 应该往哪个方向调整参数，让误差下降最快？（梯度）
- 调整多少比较合适？（学习率）

这些问题的答案都需要微积分。

---

## 核心概念

### 1. 导数：变化率

**定义**：函数在某一点的瞬时变化率

**几何意义**：曲线的切线斜率

**表示**：
```
f'(x) = df/dx = lim_{h→0} [f(x+h) - f(x)]/h
```

> **通俗解释**：
> 开车时的瞬时速度就是路程对时间的导数。
> 机器学习中：误差对参数w₁的导数 = 调整w₁时误差的"敏感度"

### 2. 常见函数的导数

这些在机器学习中经常出现：

**幂函数**：
```
d/dx (xⁿ) = n·xⁿ⁻¹
例如：d/dx (x²) = 2x
```

**指数函数**：
```
d/dx (eˣ) = eˣ
d/dx (aˣ) = aˣ·ln(a)
```

**对数函数**：
```
d/dx (ln x) = 1/x
d/dx (logₐ x) = 1/(x·ln a)
```

**Sigmoid函数**（重要！）：
```
σ(x) = 1/(1+e⁻ˣ)
σ'(x) = σ(x)·(1-σ(x))  ← 漂亮的性质
```

**ReLU函数**：
```
ReLU(x) = max(0, x)
ReLU'(x) = { 1 if x>0, 0 if x<0, 未定义 if x=0 }
```

### 3. 链式法则：神经网络的核心

**链式法则**：
```
dy/dx = (dy/du) × (du/dx)
```

多层函数的导数 = 各层导数的乘积

**神经网络中的应用**：
```
误差 E → 输出层激活 a → 隐藏层激活 z → 权重 w
dE/dw = (dE/da) × (da/dz) × (dz/dw)
```

这就是**反向传播算法**的数学基础。

### 4. 梯度：多维导数

**定义**：多变量函数在某点变化最快的方向

**表示**：
```
∇f(x₁, x₂, ..., xₙ) = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]
```

其中∂f/∂x₁是**偏导数**：其他变量固定时，f对x₁的变化率。

> **几何解释**：
> 梯度指向函数值增长最快的方向。
> 负梯度指向函数值下降最快的方向。

### 5. 最优化：找最小值

**问题**：找到参数w使得损失函数L(w)最小

**方法**：梯度下降
```
w_{new} = w_{old} - η·∇L(w_{old})
```
其中η是**学习率**（步长）

**直观理解**：
- 站在山坡上，想走到谷底
- 观察哪个方向最陡（梯度）
- 往反方向走一小步（负梯度）
- 重复直到谷底

## 机器学习中的微积分

### 1. 线性回归的梯度

损失函数（均方误差）：
```
L(w) = 1/(2m) Σ (ŷ_i - y_i)²
其中 ŷ_i = wᵀx_i + b
```

梯度：
```
∇w L = 1/m Σ (ŷ_i - y_i)·x_i
∇b L = 1/m Σ (ŷ_i - y_i)
```

> **注意**：这些公式可以直接推导出来，不需要每次都求导。

### 2. 逻辑回归的梯度

损失函数（交叉熵）：
```
L(w) = -1/m Σ [y_i·log(σ(wᵀx_i)) + (1-y_i)·log(1-σ(wᵀx_i))]
```

梯度：
```
∇w L = 1/m Σ (σ(wᵀx_i) - y_i)·x_i
```

神奇之处：梯度形式与线性回归**完全一样**，只是预测值从线性变成了σ(wᵀx_i)。

### 3. 反向传播的数学

前向传播：
```
z₁ = W₁x + b₁
a₁ = σ(z₁)
z₂ = W₂a₁ + b₂
a₂ = σ(z₂)
L = loss(a₂, y)
```

反向传播（链式法则）：
```
dL/dz₂ = dL/da₂ × da₂/dz₂
dL/dW₂ = dL/dz₂ × dz₂/dW₂ = dL/dz₂ · a₁ᵀ
dL/db₂ = dL/dz₂

dL/da₁ = W₂ᵀ · dL/dz₂
dL/dz₁ = dL/da₁ ⊙ σ'(z₁)  # ⊙是逐元素乘法
dL/dW₁ = dL/dz₁ · xᵀ
dL/db₁ = dL/dz₁
```

### 4. 自动微分

现代深度学习框架（PyTorch、TensorFlow）的核心功能：

**原理**：计算图 + 链式法则

**示例**：
```python
import torch

x = torch.tensor([1.0, 2.0], requires_grad=True)
y = x[0]**2 + 3*x[1]
y.backward()  # 自动计算梯度
print(x.grad)  # [2.0, 3.0]
```

## 重要公式

### 1. 基本导数公式

```
1. d/dx (c) = 0                     # 常数
2. d/dx (xⁿ) = n·xⁿ⁻¹              # 幂函数
3. d/dx (eˣ) = eˣ                  # 指数函数
4. d/dx (ln x) = 1/x               # 自然对数
5. d/dx (sin x) = cos x            # 三角函数
6. d/dx (cos x) = -sin x
```

### 2. 求导法则

```
加法法则：d/dx [f(x) + g(x)] = f'(x) + g'(x)
乘法法则：d/dx [f(x)·g(x)] = f'(x)g(x) + f(x)g'(x)
除法法则：d/dx [f(x)/g(x)] = [f'(x)g(x) - f(x)g'(x)] / g(x)²
链式法则：d/dx f(g(x)) = f'(g(x))·g'(x)
```

### 3. 多元函数微分

```
全微分：df = (∂f/∂x)dx + (∂f/∂y)dy + (∂f/∂z)dz
梯度：∇f = (∂f/∂x, ∂f/∂y, ∂f/∂z)
方向导数：∂f/∂u = ∇f · u  （u是单位向量）
```

## 计算示例

### 示例1：线性回归梯度推导

假设：
```
损失函数：L(w) = 1/2 (wx - y)²
预测值：ŷ = wx
```

求导：
```
dL/dw = d/dw [1/2 (wx - y)²]
      = 1/2 × 2(wx - y) × d/dw (wx - y)  # 链式法则
      = (wx - y) × x
      = (ŷ - y) × x
```

这就是线性回归的梯度公式。

### 示例2：Sigmoid导数推导

Sigmoid函数：
```
σ(x) = 1/(1+e⁻ˣ) = eˣ/(1+eˣ)
```

求导：
```
σ'(x) = d/dx [1/(1+e⁻ˣ)]
      = -1/(1+e⁻ˣ)² × d/dx (1+e⁻ˣ)  # 链式法则
      = -1/(1+e⁻ˣ)² × (-e⁻ˣ)
      = e⁻ˣ/(1+e⁻ˣ)²
      
另一种形式：
σ'(x) = σ(x) × (1-σ(x))  # 更简洁
验证：e⁻ˣ/(1+e⁻ˣ)² = [1/(1+e⁻ˣ)] × [e⁻ˣ/(1+e⁻ˣ)]
                  = σ(x) × (1-σ(x))
```

这个简洁形式在反向传播中很有用。

## 优缺点分析

### 微积分方法的优势
- **理论基础强**：有严格的数学保证
- **效率高**：梯度指向最优方向
- **通用性强**：几乎任何可微问题都能用
- **可解释性好**：梯度告诉我们每个参数的重要性

### 局限性
- **需要可微**：不可微函数无法使用梯度方法
- **局部最优**：可能陷入局部最小值而非全局最优
- **梯度消失/爆炸**：深层网络中的常见问题
- **鞍点问题**：梯度为零但不是最优点

## 实践建议

### 学习建议
1. **理解几何意义**：导数=斜率，梯度=方向
2. **手动推导几个公式**：线性回归、逻辑回归
3. **可视化梯度下降**：观察参数如何更新

### 工具推荐
- **符号计算**：SymPy（Python）
- **自动微分**：PyTorch、TensorFlow
- **可视化**：绘制损失函数曲面和梯度方向

### 常见错误
- **忘记链式法则**：多层函数求导时遗漏
- **学习率不合适**：太大导致震荡，太小导致过慢
- **梯度检查错误**：数值梯度与解析梯度不一致

## 高级话题

### 1. Hessian矩阵与二阶优化

一阶导数（梯度）告诉方向，二阶导数（Hessian）告诉曲率：

```
H = [[∂²L/∂w₁², ∂²L/∂w₁∂w₂],
     [∂²L/∂w₂∂w₁, ∂²L/∂w₂²]]
```

二阶优化方法（如牛顿法）收敛更快，但计算Hessian和其逆矩阵很昂贵。

### 2. 动量法

梯度下降的改进：
```
v_{t+1} = βv_t + (1-β)∇L(w_t)
w_{t+1} = w_t - ηv_{t+1}
```

加入动量（惯性），减少震荡，加速收敛。

### 3. 自适应学习率

根据参数的重要性调整学习率：
- AdaGrad：累计梯度平方，频繁更新的参数学习率小
- RMSProp：指数加权移动平均
- Adam：结合动量和自适应学习率（最常用）

---

## 总结

**关键要点：**
1. 导数 = 变化率 = 参数调整的敏感度
2. 梯度 = 多维导数 = 函数增长最快的方向
3. 梯度下降 = 沿负梯度方向更新参数
4. 链式法则 = 反向传播的数学基础

**核心思想：**
机器学习中的学习过程，本质上就是**沿着梯度方向调整参数，使损失函数最小化**。
