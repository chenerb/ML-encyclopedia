# 线性代数基础

## 概述

线性代数是机器学习最重要的数学工具之一。从数据表示到模型运算，几乎处处都有线性代数的身影。

本篇文章将用最直观的方式，带你理解线性代数的核心概念，即使你是数学零基础也能跟上。

---

## 为什么机器学习需要线性代数？

> **注意**：如果你不理解为什么需要学这些，很容易失去动力。

机器学习的许多运算都可以看作：

**数据 = 表格 = 矩阵**

**模型参数 = 向量**

**预测 = 矩阵乘法**

例如：
- 一张图片：28×28像素的矩阵（784个数字）
- 一个文本：词向量的集合（每个词是300维向量）
- 神经网络：层与层之间的权重矩阵

---

## 核心概念

### 1. 标量、向量、矩阵、张量

**标量（Scalar）**：单个数字
```
温度 = 25.6
价格 = 9.99
```

**向量（Vector）**：一列数字
```
一个人的特征向量 = [年龄=25, 身高=175, 体重=70, 收入=50000]
一个点的位置 = [x=3, y=4, z=5]
```

**矩阵（Matrix）**：二维数字表格
```
房价数据表：
[[面积, 房龄, 价格]
 [100,  5,   300]
 [80,   10,  250]
 [120,  2,   400]]
 
神经网络权重：
[[w11, w12, w13],
 [w21, w22, w23]]
```

**张量（Tensor）**：多维数组
```
彩色图片 = 高度 × 宽度 × 3个颜色通道
视频 = 高度 × 宽度 × 3颜色 × 时间帧
```

> **通俗解释**：
> - 标量：一个苹果
> - 向量：一袋苹果（按品种排列）
> - 矩阵：货架上的苹果（行=品种，列=产地）
> - 张量：多个货架的苹果（超市布局）

### 2. 矩阵的表示和形状

矩阵用大写字母表示：A, B, C
向量用小写字母：v, w, b
标量用普通字母：a, b, c

**矩阵形状**：(行数, 列数)
```
A = [[1, 2, 3],
     [4, 5, 6]]   # 形状：(2, 3) - 2行3列
     
v = [1, 2, 3]     # 形状：(3,) 或 3×1
```

### 3. 矩阵运算

#### 加法：对应位置相加
```
A + B = [[a₁₁+b₁₁, a₁₂+b₁₂],
         [a₂₁+b₂₁, a₂₂+b₂₂]]
```

要求：两个矩阵**形状相同**

#### 乘法：两种类型

**1. 矩阵乘法（点积）**
```
C = A · B
C的第i行第j列 = A的第i行 点乘 B的第j列
```

要求：A的列数 = B的行数
形状：A(m×n) × B(n×p) = C(m×p)

> **注意**：矩阵乘法**不满足交换律**，A·B ≠ B·A

**2. 逐元素乘法**
```
C = A ⊙ B = [[a₁₁×b₁₁, a₁₂×b₁₂],
             [a₂₁×b₂₁, a₂₂×b₂₂]]
```

要求：两个矩阵**形状相同**

#### 4. 转置：行列互换
```
A = [[1, 2, 3],
     [4, 5, 6]]
     
Aᵀ = [[1, 4],
      [2, 5],
      [3, 6]]
```

转置的性质：(Aᵀ)ᵀ = A, (A·B)ᵀ = Bᵀ·Aᵀ

### 4. 向量运算

#### 点积（内积）
```
v · w = v₁w₁ + v₂w₂ + ... + vₙwₙ
```

几何意义：衡量两个向量的相似程度
- v·w > 0：方向大致相同
- v·w = 0：相互垂直
- v·w < 0：方向大致相反

#### 范数（长度）
```
∥v∥ = √(v₁² + v₂² + ... + vₙ²)
```

常用范数：
- L2范数（欧几里得距离）：如上
- L1范数（曼哈顿距离）：|v₁| + |v₂| + ... + |vₙ|

## 机器学习中的线性代数

### 1. 线性回归的矩阵形式

**一般形式**：y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b

**矩阵形式**：ŷ = Xw + b

其中：
- X：m×n 矩阵（m个样本，n个特征）
- w：n×1 向量（权重）
- b：标量（偏置）
- ŷ：m×1 向量（预测值）

### 2. 神经网络的前向传播

神经网络每一层都是线性变换 + 非线性激活：

```
z = Wx + b      # 线性变换
a = σ(z)        # 激活函数（非线性）
```

其中：
- x：输入向量
- W：权重矩阵
- b：偏置向量
- σ：激活函数（如ReLU、Sigmoid）

### 3. 主成分分析（PCA）

PCA的核心是**特征值分解**：

```
协方差矩阵 C = XᵀX
求 C 的特征向量和特征值
取最大的k个特征向量作为主成分
```

### 4. 奇异值分解（SVD）

SVD用于推荐系统、图像压缩：

```
矩阵 A = UΣVᵀ
U：左奇异向量
Σ：奇异值（对角矩阵）
V：右奇异向量
```

## 重要公式

### 1. 矩阵乘法公式
```
(AB)_{ij} = Σ_{k=1}^n A_{ik} B_{kj}
```

### 2. 线性方程组
```
Ax = b
解：x = A⁻¹b （如果A可逆）
```

### 3. 二次型（用于损失函数）
```
f(x) = xᵀAx + bᵀx + c
常用于：最小二乘法、SVM
```

### 4. 梯度公式
```
∇(xᵀAx) = (A + Aᵀ)x
∇(bᵀx) = b
```

## 计算示例

### 示例1：房价预测

假设我们有一个简单的线性模型：
```
房价 = w₁ × 面积 + w₂ × 房龄 + b
```

数据：
```
样本1：面积=100, 房龄=5 → 价格=300
样本2：面积=80,  房龄=10 → 价格=250
样本3：面积=120, 房龄=2 → 价格=400
```

矩阵表示：
```
X = [[100, 5],
     [80,  10],
     [120, 2]]   # 3×2 矩阵
    
y = [[300],
     [250],
     [400]]      # 3×1 向量
    
w = [[w₁],
     [w₂]]       # 2×1 向量（待学习）
     
预测：ŷ = Xw + b
```

### 示例2：图片表示

一张黑白图片（28×28像素）：
```
图片矩阵 = [[pixel_11, pixel_12, ..., pixel_1,28],
            ...
            [pixel_28,1, pixel_28,2, ..., pixel_28,28]]
```

展开成向量：
```
图片向量 = [pixel_11, pixel_12, ..., pixel_28,28]  # 784维
```

## 优缺点分析

### 线性代数的优势
- **计算高效**：GPU擅长并行矩阵运算
- **理论完备**：有成熟的数学理论支撑
- **表示能力强**：可以表示各种复杂关系
- **工具丰富**：NumPy、PyTorch等库优化良好

### 局限性
- **假设线性**：许多现实关系是非线性的
- **高维诅咒**：维度太高时计算和存储成问题
- **数值稳定性**：大矩阵运算可能出现数值误差

## 实践建议

### 学习建议
1. **先理解概念，再记忆公式**
2. **结合具体问题学习**：用房价预测、图片分类等实例
3. **动手实现**：用NumPy实现矩阵运算

### 工具推荐
- **Python**：NumPy（基础）、PyTorch/TensorFlow（深度学习）
- **可视化**：理解向量、矩阵的几何意义

### 常见错误
- **混淆矩阵乘法和逐元素乘法**
- **忘记转置导致维度不匹配**
- **不理解广播（Broadcasting）规则**

---

## 总结

**关键要点：**
1. 数据 → 矩阵/向量 → 线性运算 → 结果
2. 矩阵乘法是核心，形状必须匹配
3. 转置、点积、范数是最常用操作

**数学思想：**
线性代数提供了用**结构化方式处理大量数字**的工具，这正是机器学习需要的。
