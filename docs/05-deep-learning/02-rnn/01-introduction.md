# RNN简介：会"记忆"的神经网络

## 概述

> **悬念提问**：读句子"我喜欢吃苹果"，你必须记住前面的"我喜欢吃"，才能理解"苹果"是水果而不是手机。可普通神经网络每次只看一个输入，看完就忘——它凭什么读懂有先后顺序的语言、语音、时间序列？

循环神经网络（Recurrent Neural Network, RNN）专为**序列数据**而生。它的核心特点是**有记忆**：处理当前输入时，会带上之前的信息，像人一样"顺着读"。

---

## 历史背景

### 从"前馈"到"循环"

- **1986 年**：**Jordan** 提出带反馈连接的循环结构雏形
- **1990 年**：**Elman** 提出经典的 Elman 网络（简单 RNN），序列建模奠基之作
- **1997 年**：**Hochreiter & Schmidhuber** 提出 **LSTM**，解决长期依赖问题
- **2014 年**：**GRU** 作为 LSTM 的简化版被提出

> 🧠 **费曼自问**：RNN 和普通前馈网络最大的区别是什么？——**循环连接**：RNN 的输出会作为"状态"传回自身，参与下一个时刻的计算。这个"环"就是它的记忆。

---

## 核心原理

### 1. 前馈网络的"失忆症"

普通 MLP：`输出 = f(W·x)`，每个输入独立处理，**没有先后概念**。

对"我爱北京"三个字，MLP 要么把三个字拼成一个输入，要么逐个处理但互不关联——丢失了**顺序**这个关键信息。

### 2. RNN 的"记忆环"

RNN 在每个时刻 t：

```
h_t = tanh(W·x_t + U·h_{t-1} + b)
```

- `x_t`：当前输入（如当前的字）
- `h_{t-1}`：**上一个时刻的隐藏状态**（记住的"前文"）
- `h_t`：新的隐藏状态（更新后的"记忆"）

关键：`h_{t-1}` 参与了 `h_t` 的计算——**历史信息被传递了下来**。

```
时刻1："我" → h₁
时刻2："爱" + h₁ → h₂（h₂ 里含"我"的信息）
时刻3："北" + h₂ → h₃（h₃ 里含"我爱"的信息）
```

### 3. 参数共享：同一套权重处理每个时刻

RNN 的 W、U、b 在**所有时刻共享**——同一个"阅读器"逐字读完整句，这也是它能处理变长序列的原因。

### 4. 致命缺陷：梯度消失/爆炸

记忆沿时间传递时，梯度要**反复乘以同一个权重**：

```
反向传播穿过时间（BPTT）：
梯度 ≈ W × W × W × ...（连乘 T 次）
```

- W < 1 → 梯度指数衰减 → **记不住太早的信息**（长期依赖问题）
- W > 1 → 梯度爆炸

这正是 LSTM/GRU 诞生的原因。

## 通俗解释

### RNN 是"逐字读书的人"

想象一个人读一句话："我今天早上吃了面包。"

他**一个字一个字读**，每读一个字，就在心里更新"上下文"：

- 读到"我"→ 记住"在说我"
- 读到"今天"→ 记住"说今天"
- 读到"面包"→ 结合前面，理解"吃了面包"

普通 MLP 像"把整句话剪碎扔进筐里"——没有顺序。RNN 像"顺着读、边读边记"——顺序和上下文都在。

## 📖 寓言故事：健忘的说书人

有个说书人，记性不太好。他讲故事，只能记住**最近几句**，再往前就模糊了。

讲《西游记》："唐僧师徒四人……"讲着讲着，忘了前面说过"孙悟空被压五行山"，于是故事断断续续，听众听得一头雾水。

有人问他："你为什么不把开头记牢？"

说书人叹气："我只有一个小口袋，**每说一句，就把新的塞进去、旧的挤出来**。说得越长，开头的记忆就越淡。"

他试着把口袋换大，却发现新问题——旧记忆没挤出去，越积越多，最后脑袋"撑爆"，讲得语无伦次。

老听众点拨他："你要的不是一个'只能装最近几句'的口袋，而是一个**能选择'哪些该留、哪些该忘'的聪明账本**。"

说书人恍然大悟，换了个"会挑重点"的账本，从此故事讲得又长又完整。

> **寓意**：简单 RNN 就像那个"只能记住最近几句"的小口袋——记忆随序列变长而**指数衰减（梯度消失）**，记不住太早的信息。要解决"长期依赖"，需要 LSTM/GRU 那样"**该记的记、该忘的忘**"的门控机制。

## 优缺点分析

### 优点
- **天然适合序列**：保留顺序和上下文信息
- **参数共享**：一套权重处理任意长度序列
- **灵活**：可处理输入/输出都是序列的任务

### 缺点
- **梯度消失/爆炸**：难以学习长期依赖
- **串行计算慢**：每个时刻依赖上一时刻，无法并行
- **长期记忆弱**：简单 RNN 记不住太早的信息
- **已被 Transformer 部分取代**：但思想仍是序列建模基础

## 应用场景

- **文本生成**：逐字生成文章
- **机器翻译**：编码-解码结构

- **时间序列预测**：股票、天气、销量
- **情感分析**：判断评论的正负面

## 总结

**关键要点：**
1. RNN 通过"循环连接"拥有记忆，适合序列数据
2. 核心公式：h_t = f(W·x_t + U·h_{t-1})
3. 参数在所有时刻共享
4. 梯度消失导致长期依赖难题，催生了 LSTM/GRU
