# 社区和论坛：找到同行的路

## 概述

学习 AI 的路上，你不需要一个人走。活跃的社区能帮你答疑解惑、获取前沿资讯、找到志同道合的伙伴。这里整理了国内外优质的学习社区。

---

## 🌍 国际社区

| 社区 | 特点 |
|------|------|
| **GitHub** | 开源代码、项目、论文复现 |
| **Stack Overflow** | 技术问答，遇到 bug 先搜这里 |
| **Kaggle** | 数据竞赛、数据集、Notebook |
| **Reddit（r/MachineLearning）** | 前沿论文、行业讨论 |
| **Hugging Face** | 模型、数据集、Demo 社区 |
| **Papers with Code** | 论文 + 代码一站式 |

---

## 🇨🇳 中文社区

| 社区 | 特点 |
|------|------|
| **Datawhale** | 开源学习社区，组队学习、实战 |
| **知乎（机器学习话题）** | 深度讨论、经验分享 |
| **B站（李沐等 UP 主）** | 视频教程、论文精读 |
| **CSDN / 掘金** | 技术博客、教程 |
| **机器之心 / 量子位** | AI 资讯媒体 |
| **极市平台** | 计算机视觉社区 |

---

## 🎓 学术社区

| 社区 | 特点 |
|------|------|
| **arXiv** | 论文预印本，追前沿必看 |
| **Google Scholar** | 文献检索、引用追踪 |
| **顶会** | NeurIPS、ICML、CVPR、ACL、ICLR |

---

## 💬 交流与提问的艺术

1. **先搜索再提问**：大多数问题已有答案
2. **提问要具体**：贴代码、报错、你尝试了什么
3. **学会读官方文档**：文档是第一手资料
4. **输出倒逼输入**：写博客、做分享、参与开源
5. **组队学习**：加入 Datawhale 等社区，结伴前行

---

## 如何利用社区

- **学习阶段**：跟 Datawhale 组队、看 B 站教程、刷 Kaggle
- **遇到问题**：GitHub Issues、Stack Overflow
- **追前沿**：arXiv + Papers with Code + 机器之心
- **进阶输出**：写博客、开源项目、打比赛
