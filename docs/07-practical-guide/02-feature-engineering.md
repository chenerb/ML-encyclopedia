# 特征工程：点石成金的艺术

## 概述

> **悬念提问**：同样一份数据，有人只能做出 70 分的模型，有人却能做出 90 分——差距不在算法，而在**特征**。好的特征能让简单模型封神，坏的特征能让复杂模型翻车。特征工程，就是这门"点石成金"的手艺。

特征工程（Feature Engineering）是从原始数据中**构造、选择、变换**特征的过程。它是传统机器学习的核心竞争力，也是深度学习时代仍不可忽视的基本功。

---

## 核心内容

### 1. 特征变换

- **对数变换**：把长尾分布拉近正态（如收入、价格）
- **标准化/归一化**：统一量纲
- **离散化**：连续值分箱（年龄 → 青年/中年/老年）
- **Box-Cox 变换**：让数据更接近正态

### 2. 特征构造（组合出新的）

- **加减乘除**：如"客单价 = 总金额 / 订单数"
- **统计特征**：近 7 天均值、方差、趋势
- **交叉特征**：两个特征的组合（如"年龄×收入"）
- **时间特征**：从日期拆出星期、是否节假日、距上次的天数

### 3. 特征选择（去掉没用的）

| 方法 | 思路 |
|------|------|
| **过滤法** | 按相关性、方差、卡方检验筛 |
| **包裹法** | 用模型性能做筛选（如递归特征消除）|
| **嵌入法** | 模型自带（L1 正则、树模型的特征重要性）|

### 4. 特征编码

- 独热编码、标签编码、目标编码、词嵌入（见数据预处理篇）

### 5. 领域知识

**最好的特征往往来自对业务的理解**。如预测房价，老中介知道"学区""朝向"比"门牌号"重要得多——这就是领域知识。

---

## 为什么特征工程重要

```
好特征 + 简单模型 > 差特征 + 复杂模型
```

特征决定了**数据的上限**，模型只是逼近这个上限。深度学习之所以强，正是因为它**自动学特征**——但理解"好特征长什么样"，依然是设计网络、排查问题的关键。

## 📖 寓言故事：点石成金

两个淘金客在同一片河滩淘金。

甲每天拼命淘，把河沙**原封不动**倒进筛子，累死累活，一天淘出几粒金砂。

乙却不急着淘，而是先**琢磨**：哪段河滩金砂多？什么颜色的沙含金高？他据此**挑地段、调筛子**，还发明了"先粗筛、再细筛"的法子。

同样的河沙，乙淘出的金子是甲的十倍。

甲不服："咱们淘的是同一片沙，凭什么？"

乙说："沙是一样的沙，但**你怎么处理沙，决定了你能淘出多少金**。我把没用的石头先筛掉（特征选择），把含金的沙富集起来（特征构造），再上细筛（模型）。你呢？把石头和沙一起倒进去，金砂都被石头埋住了。"

> **寓意**：特征工程就是"淘金的筛法"——**从原始数据里构造、选择、变换出真正有信号的特征**。好特征让简单模型也能"淘出金"，坏特征让复杂模型"被石头埋住"。

---

## 实践建议

- **先理解业务，再做特征**：领域知识是无价的
- **别一上来就堆几百个特征**：先做特征选择，防止维度灾难
- **注意特征泄漏**：别用"未来才知道"的信息做特征（如用"是否已流失"预测流失）
- **树模型对量纲不敏感**，但线性模型/神经网络敏感——特征变换要看模型

## 总结

**关键要点：**
1. 特征工程 = 变换 + 构造 + 选择 + 编码
2. 好特征决定数据上限，模型只是逼近
3. 领域知识是最好的特征来源
4. 警惕特征泄漏（用未来信息做特征）
