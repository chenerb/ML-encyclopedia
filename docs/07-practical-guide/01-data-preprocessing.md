# 数据预处理：磨刀不误砍柴工

## 概述

> **悬念提问**：为什么两个程序员用同样的算法，一个模型效果拔群，一个却一塌糊涂？差别往往不在算法，而在**数据干不干净**。机器学习界有句名言："垃圾进，垃圾出"——喂给模型的数据质量，决定了模型的上限。

数据预处理是机器学习项目的**第一步**，也是最耗时、最决定成败的一步。它把原始数据"洗干净、整理好"，让模型能高效学习。

---

## 核心内容

### 1. 数据清洗：处理"脏数据"

**缺失值处理：**

| 方法 | 适用场景 |
|------|---------|
| 删除 | 缺失很少，且删除不影响分布 |
| 填充均值/中位数 | 数值型特征 |
| 填充众数 | 类别型特征 |
| 用模型预测填充 | 缺失有规律时 |

**异常值处理：**
- 检测：箱线图、3σ 原则、孤立森林
- 处理：删除、截断、或用稳健统计量替换

**重复值**：去重，避免样本被重复计算

### 2. 数据标准化 / 归一化

让不同量纲的特征"公平竞争"：

- **标准化（Z-score）**：`(x − μ) / σ`，使均值为 0、方差为 1
- **归一化（Min-Max）**：缩放到 [0, 1]
- **必须标准化**：KNN、SVM、K-Means、神经网络、带正则的线性模型
- **可不标准化**：决策树、随机森林、朴素贝叶斯

### 3. 编码：把"文字"变成"数字"

模型只能吃数字，类别特征要编码：

- **独热编码（One-Hot）**：每个类别一个 0/1 位
- **标签编码（Label Encoding）**：类别 → 整数（有顺序时才用）
- **词嵌入（Embedding）**：文本 → 稠密向量

### 4. 数据划分

```
训练集（70%）→ 训练模型
验证集（15%）→ 调超参数
测试集（15%）→ 最终评估（只测一次！）
```

> **警告**：标准化等预处理**必须在划分后、只在训练集上拟合**，再应用到验证/测试集——否则会"数据泄漏"，评估虚高。

### 5. 类别不平衡处理

- **重采样**：欠采样多数类 / 过采样少数类（SMOTE）
- **调整权重**：给少数类更高的误分类代价
- **换指标**：用精确率/召回率/AUC，而非准确率

## 📖 寓言故事：名厨的备料

两位厨师做同一道菜，用同一套菜谱（算法）。

甲厨师拿到食材，**洗也不洗、切也不切**，整颗菜带泥扔进锅——出锅的菜又腥又苦。

乙厨师却不急着下锅，先花一小时**备料**：

- 坏叶子摘掉（删异常值）
- 泥土洗净（清洗）
- 菜切成大小均匀的段（标准化）
- 肉、菜分门别类摆好（编码、划分）

同样的菜谱，乙厨师炒出来的菜鲜香可口。

甲厨师不服："菜谱一样，凭什么他做得好？"

老师傅说："**菜谱决定你能做多好，食材决定你能做多烂。** 好厨师七分功夫在备料，三分在火候。你拿烂食材下锅，再好的菜谱也救不回来。"

> **寓意**：数据预处理就是"备料"——**清洗、标准化、编码、划分**。算法（菜谱）再强，喂进去脏数据（烂食材）也白搭。"垃圾进、垃圾出"是机器学习的第一铁律。

---

## 实践建议

- **先做探索性分析（EDA）**：画分布图、统计缺失率，别盲目动手
- **标准化要"防泄漏"**：只在训练集上 fit，再 transform 到验证/测试集
- **缺失值别乱填**：先分析缺失是否有规律（随机缺失 vs 有偏缺失）
- **类别不平衡先处理**：否则模型可能"全预测多数类"

## 总结

**关键要点：**
1. 数据预处理是机器学习的第一步，决定成败
2. 核心：清洗、标准化、编码、划分、平衡
3. 标准化要防数据泄漏（只在训练集 fit）
4. "垃圾进、垃圾出"是第一铁律
