# 训练策略：让模型"练得更好"的兵法

## 概述

> **悬念提问**：同样的模型、同样的数据，有人训练一小时就收敛，有人训练三天还在原地打转。差距在哪？在**训练策略**——学习率怎么设、批量多大、要不要预热、何时早停。这些"练兵之法"，决定了训练的成败。

训练策略（Training Strategy）是让模型训练更稳、更快、更好的实用技巧集合。它像"练兵之道"，是资深工程师与新手的分水岭。

---

## 核心内容

### 1. 学习率调度

训练不同阶段用不同学习率：

- **阶梯衰减**：每 N 轮学习率减半
- **余弦退火**：学习率按余弦曲线平滑下降
- **Warmup**：先用小学习率"热身"几轮，再升到目标值（大模型标配）

### 2. 批量大小（Batch Size）

- 大批量：梯度估计稳，但可能泛化差、内存大
- 小批量：噪声大但正则效果好
- 常见取值：32、64、128、256

### 3. 正则化组合

防过拟合"三件套"：**L2 权重衰减 + Dropout + 早停**，根据过拟合程度组合使用。

### 4. 早停（Early Stopping）

监控验证集误差，一旦开始上升就停——防止过拟合，还能省算力。

### 5. 梯度裁剪（Gradient Clipping）

梯度范数超过阈值就裁剪，防止梯度爆炸（RNN、Transformer 常用）。

### 6. 迁移学习

先用大规模预训练模型，再在小数据上微调——小数据任务的"捷径"。

```
ImageNet 预训练 → 切掉分类头 → 接新任务 → 微调
```

### 7. 数据增强

训练时对数据做随机变换（翻转、裁剪、加噪），变相扩大数据集、提升泛化。

---

## 一个典型的训练流程

```
① 数据准备 + 标准化
② 小批量随机梯度下降
③ Warmup 热身 → 余弦退火
④ 每轮监控验证集，早停
⑤ 梯度裁剪防爆炸
⑥ 必要时迁移学习 / 数据增强
```

## 📖 寓言故事：练兵之道

两位将军各练一支新兵。

甲将军急于求成，第一天就**上最重的训练量**（大学习率），结果新兵累垮一片、士气涣散（梯度爆炸）。

乙将军却深谙练兵之道：

1. **先热身**：头几天轻量训练，让新兵适应（warmup）
2. **循序渐进**：逐渐加量，到后期再减量巩固（学习率调度）
3. **及时喊停**：见士兵状态下滑、开始"练废"，立即停止（早停）
4. **防走火**：个别士兵训练过猛，及时拉回来（梯度裁剪）
5. **变着花样练**：换地形、换天气练（数据增强）

三个月后，乙将军的新兵成了精兵，甲将军的新兵却伤的伤、逃的逃。

甲将军请教。乙将军说："练兵不是'越狠越好'，而是**张弛有度、因势利导**。该热身热身，该收就收，才能练出真本事。"

> **寓意**：训练策略就是"练兵之道"——**warmup 热身、学习率调度、早停、梯度裁剪、数据增强**，让模型训练更稳更快。蛮干不如巧练。

## 实践建议

- **先画损失曲线**：训练/验证损失曲线是最重要的"仪表盘"
- **学习率是头号旋钮**：优先调它
- **早停几乎必开**：零成本防过拟合
- **大模型必用 warmup + 梯度裁剪**
- **小数据优先迁移学习 + 数据增强**

## 总结

**关键要点：**
1. 训练策略是让训练更稳更快的技巧集合
2. 核心：学习率调度、批量、正则化、早停、梯度裁剪
3. 迁移学习 + 数据增强是小数据的利器
4. 损失曲线是最重要的"仪表盘"
