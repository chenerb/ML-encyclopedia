# 超参数调优：找到最佳的"旋钮位置"

## 概述

> **悬念提问**：模型选好了，可还有一堆"旋钮"要拧——学习率多大？树的深度多少？正则化系数取几？这些旋钮（超参数）调得好坏，能让模型性能天差地别。问题是：旋钮这么多，怎么科学地拧？

超参数调优（Hyperparameter Tuning）是寻找最优超参数组合的过程。它不像模型参数那样靠训练自动学，而是需要人工设定、反复试验。

---

## 核心内容

### 1. 参数 vs 超参数

| 类型 | 例子 | 如何确定 |
|------|------|---------|
| **模型参数** | 权重 w、偏置 b | 训练时自动学习 |
| **超参数** | 学习率、树的深度、K 值 | 人工设定、调优 |

### 2. 常见超参数

- **学习率**：最关键的旋钮，太大发散、太小太慢
- **正则化系数 λ**：控制过拟合
- **树模型**：max_depth、n_estimators、min_samples_split
- **KNN**：K 值
- **神经网络**：层数、神经元数、batch size、Dropout 率

### 3. 三种调优方法

**① 网格搜索（Grid Search）**

穷举所有组合，逐一验证：

```
max_depth ∈ {3, 5, 7}, n_estimators ∈ {100, 200}
→ 6 种组合全试一遍
```

- 优点：全面、可并行
- 缺点：组合多时爆炸（维度灾难）

**② 随机搜索（Random Search）**

在超参数空间随机采样 N 组，取最好的：

- 优点：效率高，常用于高维空间
- 缺点：可能漏掉最优

**③ 贝叶斯优化（Bayesian Optimization）**

根据历史结果，智能地选择下一组"更可能好"的参数：

- 优点：效率最高，适合昂贵训练
- 缺点：实现复杂

### 4. 用交叉验证评估每组参数

每组超参数用**交叉验证**评估，取平均性能最优的组合——避免"某组参数恰好运气好"。

## 📖 寓言故事：老收音机的旋钮

一台老收音机，收不到台，全是杂音。上面有好几个旋钮：音量、微调、波段。

新手小张上去乱拧一通，越拧越糟。

老师傅老李却有条不紊：

1. 先调**波段**（选大方向，像选模型）
2. 再慢慢转**微调**（细调，像调学习率）
3. 边转边听，**听清一点就记住，往更清的方向继续**（像搜索策略）

老李还总结："**一次只动一个旋钮**，动了就听效果。全拧乱了，你都不知道是哪个旋钮起的作用。"

"而且——"老李补了一句，"旋钮不是越多越好，**找准最影响声音的那一两个，重点调**。"

几下功夫，收音机里传出了清晰的广播声。

> **寓意**：超参数调优就是"拧旋钮"——**用网格/随机/贝叶斯搜索，科学地试不同组合，用交叉验证评估**。关键在"一次只动一个、重点调最影响的"。

## 实践建议

- **先粗调再细调**：先用对数刻度粗扫（0.1、0.01、0.001），再精细搜索
- **重点调最敏感的**：学习率、树的深度通常是关键
- **用随机搜索起步**：高维空间比网格搜索高效
- **记录每次实验**：参数、结果、日志，方便复盘
- **别在测试集上调**：调参只用验证集

## 总结

**关键要点：**
1. 超参数靠人工设定，需反复调优
2. 三大方法：网格、随机、贝叶斯
3. 用交叉验证评估每组参数
4. 重点调最敏感的（学习率等）
