# GPT系列 (2018-2023)：从预测下一个词到改变世界

## 概述

> **悬念提问**：一个只会"预测下一个词"的模型，凭什么能写文章、写代码、陪你聊天、通过考试？GPT 系列用五年时间证明了一件惊人的事：**把"预测下一个词"这件事做到极致，智能就会涌现**。

GPT（Generative Pre-trained Transformer）是 OpenAI 的系列大语言模型。从 GPT-1 到 GPT-4，它用**自回归生成 + 海量数据 + 超大参数**，一步步逼近通用智能。

---

## 历史背景

### 五年四代，能力跃迁

| 版本 | 年份 | 参数量 | 里程碑 |
|------|------|--------|--------|
| **GPT-1** | 2018 | 1.1 亿 | 证明"生成式预训练"可行 |

> 🧠 **费曼自问**：GPT 的核心思想是什么？——**"预测下一个词"**。给它一段文字，让它预测下一个词；预测对了就强化。这个看似简单的任务，逼模型学会了语法、知识、推理——因为要预测下一个词，必须先"理解"前文。

---

## 核心创新

### 1. 只用解码器，自回归生成

GPT 只用 Transformer 的**解码器**，从左到右逐词生成：

```
"今天天气" → 预测下一个词 → "很好" → "今天天气很好" → 预测 → "，" → ...
```

### 2. 预训练：海量文本学语言

在互联网海量文本上做"预测下一个词"的预训练，学会语言的统计规律和世界知识。

### 3. 缩放定律：越大越强

GPT 系列的核心发现：**模型参数、数据、算力同步扩大，能力持续提升**，且没有明显瓶颈。

```
GPT-1(1亿) → GPT-2(15亿) → GPT-3(1750亿) → GPT-4(万亿?)
能力：     写句 → 写段 → 写文 → 多模态推理
```

### 4. RLHF：让模型"听话"

ChatGPT 的关键技术是**基于人类反馈的强化学习（RLHF）**：让人给模型的回答打分，模型学习"什么样的回答是人想要的"——从"会说话"到"说人话"。

## 📖 寓言故事：爱接话的孩子

有个孩子，特别喜欢"接话"。别人说上半句，他就猜下半句。

"床前明月——" 他接："光！"
"疑是地上——" 他接："霜！"

起初他接得驴唇不对马嘴。可他不气馁，**每天读海量的书，练"接话"**。读到天文地理、诗词歌赋、数理逻辑，他都要练着接一句。

神奇的是，接了几十年的话，他变得**无所不知**：

- 你问他数学题，他"接"出答案
- 你让他写文章，他"接"出一篇
- 你和他聊天，他"接"得头头是道

有人惊叹："你不是只会接话吗？"

他笑："**要接对下一句，就得先听懂上一句**。我练了亿万次'接话'，其实是在练'理解'。接话接到极致，就是智能。"

> **寓意**：GPT 的核心就是"预测下一个词"（接话）。**这个简单任务逼模型学会了理解前文、掌握知识、进行推理**——把"接话"做到极致，智能便涌现出来。
