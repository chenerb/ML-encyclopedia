# ResNet (2015)：给梯度留一条"捷径"

## 概述

> **悬念提问**：VGG 堆到 19 层就到头了——再深，梯度就消失、网络训不动。可 2015 年，有人把网络堆到了 **152 层**，效果还更好。秘诀是什么？答案朴素得惊人：**给梯度留一条不绕弯的"捷径"**。

残差网络（Residual Network, ResNet）是 2015 年的划时代突破。它引入**残差连接（跳连）**，一举解决了深层网络的梯度消失问题，把网络深度推进到百层以上。

---

## 历史背景

- **2015 年**：微软亚洲研究院 **何恺明（Kaiming He）** 等人提出 ResNet
- 在 ImageNet 上以 152 层夺冠，错误率 3.57%，**首次超越人类水平**（约 5%）
- ResNet 成为此后几乎所有视觉任务的"标准底座"，影响延续至今

> 🧠 **费曼自问**：为什么网络"越深反而越差"？——不是表达力不够，而是**优化困难**：层太深时梯度连乘趋近 0，浅层收不到更新信号。ResNet 的残差连接让梯度能"抄近道"直达浅层，深度才真正兑现红利。

---

## 核心创新

### 1. 残差连接：让网络学"差值"

普通网络直接学习目标映射 H(x)。ResNet 改学**残差** F(x) = H(x) − x：

```
输出 = F(x) + x
       （残差）  （恒等捷径）
```

那个 **+ x** 就是"跳连"——把输入**原样**加到输出上，绕过了中间的卷积层。

### 2. 为什么能解决梯度消失

反向传播求导时：

```
∂(F(x)+x)/∂x = ∂F/∂x + 1
```

那个 **+ 1** 保证梯度至少能"原样"传回浅层，**不会被连乘衰减到 0**。

```
普通网络：梯度 = W × W × W × ...（连乘，指数衰减）
ResNet：  梯度 = (∂F/∂x + 1) × (∂F/∂x + 1) × ...（每层至少 +1，不衰减）
```

### 3. 残差块结构

```
输入 x ──→ 卷积 → ReLU → 卷积 ──→ (+) → ReLU → 输出
    └──────────── 捷径（恒等映射）──────┘
```

每个残差块学的是"**在 x 的基础上做的小调整**"，而非从头学。

### 4. 深度：18 → 152 层

ResNet 有 18、34、50、101、152 层多个版本，最深 152 层。深度带来的收益第一次被完全兑现。

---

## 为什么说"学残差比学原函数容易"

如果理想映射接近恒等（很多层其实不需要"大改"），那么：

- 普通网络要学 H(x)≈x，得精确拟合恒等映射，很难
- ResNet 只需学 F(x)≈0（让残差归零），把权重推到 0 即可，**容易得多**

## 📖 寓言故事：抄近道的信使

从前有个王国，从王都到边疆要经过 152 个驿站。军令靠驿站**一个传一个**传递。

问题来了：传令兵每过一站，口令就模糊一点。传到第 20 站，口令已经听不清了；再往后，彻底传不下去（梯度消失）。

国王愁眉不展。一位聪明的将军出了个主意：

"在每个驿站旁，**修一条直达下下个驿站的近道**。传令兵不用一站站绕，可以**抄近道**，把口令原样带到更远的地方。"

果然，有了近道，军令**几乎不衰减**地传遍了 152 个驿站，边关第一次收到了清晰的命令。

将军解释："原来的问题，不是驿站不够多，而是**口令在层层传递中不断衰减**。近道让口令能'原样跳过'好几站，衰减自然就没了。"

> **寓意**：ResNet 的残差连接就是那条"近道"——**梯度通过跳连（+x）原样传回浅层，不再被层层连乘衰减**。解决了梯度消失，网络才能深到 152 层，深度红利才真正兑现。

## 影响与遗产

- **解决梯度消失**：让百层网络成为可能
- **超越人类**：ImageNet 错误率首次低于人类
- **成为标准底座**：几乎所有视觉任务都用 ResNet 预训练
- **思想扩散**：残差连接被 Transformer、扩散模型等广泛借用

## 总结

**关键要点：**
1. ResNet 用残差连接（跳连）解决梯度消失
2. 每个块学"差值" F(x)，输出 = F(x) + x
3. 求导后的 "+1" 让梯度直达浅层
4. 152 层超越人类，成为视觉任务标准底座
