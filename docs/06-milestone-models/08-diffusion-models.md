# 扩散模型 (2020-)：从噪声中"浮现"的画

## 概述

> **悬念提问**：给你一屏电视雪花（纯随机噪声），你能从中"看出"一幅画吗？扩散模型说：能。它做的是一件反直觉的事——先学"怎么把画一步步变成噪声"，然后把这个过程**倒着放**，就能从噪声中一点点"变"出画来。

扩散模型（Diffusion Model）是 2020 年代最强大的生成模型，Stable Diffusion、DALL·E、Midjourney 等文生图神器都建立其上。它用"加噪→去噪"的优雅思路，把生成质量推到了新高度。

---

## 历史背景

- **2015 年**：扩散模型的数学思想（非平衡热力学）被引入机器学习
- **2020 年**：**DDPM**（去噪扩散概率模型）让扩散模型效果起飞
- **2022 年**：**Stable Diffusion** 开源，文生图席卷全球；DALL·E 2 商用
- **2024 年**：**Sora** 把扩散用于视频生成，震惊世界

> 🧠 **费曼自问**：扩散模型的核心直觉是什么？——**"毁掉容易，重建难"**。把一张清晰的画逐步加噪声，毁成雪花，这个过程很容易定义；反过来，学一个模型**逐步去噪**，把雪花一点点还原成画，就学会了"生成"。

---

## 核心原理

### 1. 前向过程：加噪（毁掉）

给一张真实图片，逐步加高斯噪声，经过 T 步后变成纯噪声：

```
清晰图 x₀ → 加噪 → x₁ → 加噪 → ... → x_T（纯噪声）
```

这个过程**不需要学习**，是人为定义的（每步加固定量的噪声）。

### 2. 反向过程：去噪（重建）

训练一个模型，学习**如何从 x_t 还原出 x_{t-1}**（即"去掉一步噪声"）：

```
纯噪声 x_T → 去噪 → ... → x₁ → 去噪 → x₀（清晰图）
```

模型学会"去噪"，就学会了"从噪声生成内容"。

### 3. 生成：从噪声出发

生成时，采样一个纯噪声，让模型一步步去噪，最终"浮现"出一张图：

```
随机噪声 → [去噪×T步] → 一张全新的图
```

### 4. 文生图：加个"提示词"

在去噪时**把文字提示词也输入模型**（如 Stable Diffusion），模型就学会了"按你的描述去噪"，生成对应的图。

```
"一只戴墨镜的猫" + 噪声 → [条件去噪] → 戴墨镜的猫的图
```

---

## 为什么扩散模型赢了

| 优势 | 说明 |
|------|------|
| **质量极高** | 生成图像清晰、逼真，超越 GAN |
| **训练稳定** | 没有 GAN 的对抗博弈，不易崩溃 |
| **可控性强** | 文字、草图、参考图都能引导生成 |
| **多样性好** | 不易模式崩溃 |

## 📖 寓言故事：复原碎纸的巧匠

一个巧匠有个绝活：能**把撕碎的纸片复原成完整的画**。

别人问他怎么练的。他说：

"我先练'**撕**'——把一幅好画，一点一点撕碎，直到碎成纸屑。这个过程很简单，人人会。"

"然后我练'**拼**'——看着一堆纸屑，学着**一步步把纸屑拼回原样**。哪片该拼在哪、哪片该先拼……我练了千万遍。"

"练成之后，神奇的事发生了：你随便给我一堆纸屑，我都能拼出一幅**全新而完整**的画。因为我早就学会了'**纸屑是如何一步步变成画的**'。"

有人问："那给你一堆纸屑，拼出来的画，是原来那幅吗？"

巧匠笑："不是——是**一幅新的画**。我学会的是'拼'的本事，不是'记住某幅画'。所以每次拼，都能拼出不同的新画。"

> **寓意**：扩散模型就是这位巧匠——**先定义"加噪撕碎"的过程，再学"去噪复原"的本事**。学会了"从噪声一步步重建"，就能从随机噪声生成全新的内容。文生图不过是"照着提示词去复原"。

## 总结

**关键要点：**
1. 扩散模型 = 加噪（毁掉）+ 去噪（重建）的逆过程
2. 前向加噪不需学习，反向去噪是学习目标
3. 学会去噪就学会生成，从噪声"浮现"内容
4. 质量高、训练稳，成为生成式 AI 新霸主
