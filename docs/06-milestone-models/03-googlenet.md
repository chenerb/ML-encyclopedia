# GoogLeNet (2014)：并联的智慧

## 概述

> **悬念提问**：VGG 靠"堆深"取胜，可层数一深，参数就爆炸、计算就吃力。有没有一条**不靠蛮力堆深**的路？2014 年的冠军 GoogLeNet 给出了答案：既然不知道用多大的卷积核好，那就**同时用多种，并联起来**。

GoogLeNet（又称 Inception）是 2014 年 ImageNet 冠军。它发明了 **Inception 模块**，用"并联多尺度卷积"的思路，在更深的网络里反而用更少的参数。

---

## 历史背景

- **2014 年**：Google 团队（Szegedy 等人）提出 GoogLeNet
- 名字致敬 LeNet，加上 Google 的"Goog"
- 以 22 层网络夺冠，参数量却只有 AlexNet 的 1/12

> 🧠 **费曼自问**：GoogLeNet 的"并联"解决什么问题？——图像里的物体大小不一：大物体需要大卷积核看，小物体需要小卷积核看。与其纠结"用哪个"，不如**1×1、3×3、5×5 同时上，并联输出再拼接**，让网络自己选。

---

## 核心创新

### 1. Inception 模块：多尺度并联

一个 Inception 模块同时做多种卷积，再把结果拼起来：

```
输入
 ├─ 1×1 卷积 →（看精细局部）
 ├─ 3×3 卷积 →（看中等范围）
 ├─ 5×5 卷积 →（看大范围）
 └─ 3×3 池化 →（看整体）
        ↓
   拼接（通道维度合并）
```

### 2. 1×1 卷积：降维减参的"省钱神器"

直接堆大卷积核参数太多。GoogLeNet 的妙招：**先用 1×1 卷积压缩通道数**，再做大卷积，参数骤减。

```
直接 5×5 卷积：参数巨大
先 1×1 降维 → 再 5×5 卷积：参数大幅减少
```

### 3. 去掉全连接层

VGG 的全连接层占了大量参数。GoogLeNet 改用**全局平均池化**替代，参数量进一步下降。

### 4. 辅助分类器

在网络中间加"辅助分类器"，缓解梯度消失（后来的网络发现这个作用其实有限，但体现了当时的探索）。

---

## 结果：更深，却更轻

| 网络 | 层数 | 参数量 |
|------|------|--------|
| AlexNet | 8 | ~6000 万 |
| VGG-16 | 16 | ~1.38 亿 |
| **GoogLeNet** | **22** | **~500 万** |

22 层的 GoogLeNet，参数只有 VGG 的 1/27，却拿了冠军——"并联 + 降维"的威力可见一斑。

## 📖 寓言故事：多管齐下的侦探

一个侦探要在一张照片里找线索，照片里的物体**大小不一**：有远景的大楼，有近景的纽扣。

笨侦探只有一种放大镜，看大物体嫌小、看小物体嫌大，顾此失彼。

聪明的 GoogLeNet 侦探却带了一套**四个镜头**：

- 微距镜头（1×1）看精细局部
- 标准镜头（3×3）看中等范围
- 广角镜头（5×5）看大场景
- 全景镜头（池化）看整体

他**四个镜头同时看**，把看到的东西拼在一起，大小线索一个不漏。

有人问："带四个镜头不重吗？"

他笑："我每个镜头都很轻，还配了个'聚焦器'（1×1 降维）先把画面压缩再细看。**四个轻镜头并联，比一个大重镜头看得更全、更省力。**"

> **寓意**：Inception 模块就是"多镜头并联"——**1×1、3×3、5×5、池化同时提取多尺度特征，再拼接**，并用 1×1 卷积降维减参。它证明了"并联的智慧"：不靠蛮力堆深，也能又深又轻。

## 影响与遗产

- **开创多尺度并联**：Inception 思想影响深远
- **证明 1×1 卷积的降维价值**：成为后续网络的常用技巧
- **用全局平均池化替代全连接**：大幅减参
- **后续演进**：Inception v2/v3/v4、Xception 持续改进

## 总结

**关键要点：**
1. GoogLeNet 用 Inception 模块并联多尺度卷积
2. 1×1 卷积降维，大幅减少参数
3. 22 层却只有 500 万参数，拿了 2014 冠军
4. 开创了"并联 + 降维"的设计思路
