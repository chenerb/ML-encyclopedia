# BERT (2018)：读懂上下文的双向模型

## 概述

> **悬念提问**："苹果"是水果还是手机？光看这个词本身，无法判断——得看**前后文**。可 GPT 只能"从左往右"读（看到前面的），看不到后面的词。2018 年，BERT 说：我要**同时看前后两边**。

BERT（Bidirectional Encoder Representations from Transformers）是 2018 年 Google 发布的预训练语言模型。它首创"**双向**"理解，并确立了"**预训练 + 微调**"的范式，让 NLP 进入新时代。

---

## 历史背景

- **2018 年**：Google 发布 BERT
- 在 11 项 NLP 任务上刷新纪录（GLUE 基准大幅提升）
- 论文名《BERT: Pre-training of Deep Bidirectional Transformers》
- 开启了"预训练大模型 + 下游微调"的时代

> 🧠 **费曼自问**：BERT 的"双向"为什么重要？——语言理解需要**上下文**："他吃了一个苹果"里的"苹果"是水果，"他买了一个苹果"可能是手机。只看左边（GPT 式）会漏掉右边信息，BERT 同时看两边，理解更准。

---

## 核心创新

### 1. 只用编码器，双向理解

Transformer 有编码器和解码器。BERT **只用编码器**，因此每个词都能同时看到整句的所有词（双向），而非只能看左边。

### 2. 两个预训练任务

**① 掩码语言模型（MLM，完形填空）**

随机盖住句中的一些词，让模型根据上下文猜出来：

```
"今天天气真 [MASK]，我们出去玩吧。"
→ 模型预测 [MASK] = "好"
```

因为要"填空"，模型被迫学会**理解上下文**。

**② 下一句预测（NSP）**

给两句，判断第二句是否是第一句的下一句，学习句子间关系。

### 3. 预训练 + 微调范式

```
预训练：在海量无标注文本上学"语言规律"（MLM、NSP）
   ↓
微调：在具体任务的小数据上，接一个任务头，继续训练
```

这是 BERT 最重要的范式贡献——**一个预训练模型，适配无数下游任务**。

## 为什么是里程碑

| 贡献 | 意义 |
|------|------|
| **双向理解** | 首次让语言模型同时看前后文 |
| **预训练+微调** | 从"每个任务从头训"到"一个底座打天下" |
| **MLM 任务** | 巧妙的"完形填空"让无标注文本也能训练 |
| **刷新纪录** | 11 项 NLP 任务登顶，震动学界 |

## 📖 寓言故事：会填空的读书人

从前有个读书人，读文章有个怪习惯：他总爱**把文章里的字蒙住几个，再根据前后文猜出来**。

比如："今天天气很 [蒙住]，我们出门踏青吧。" 他一猜："好！因为后面说'出门踏青'，说明天气不错。"

"这道菜真 [蒙住]，我吃了三碗饭。" 他一猜："香！因为后面说'吃了三碗'。"

日复一日地"填空"，他练就了一身**"看前后、猜中间"**的本领——对文字的理解远超只"从左往右读"的人。

有人问他为什么这么厉害。他笑：

"我从不孤立地看一个词。**一个词是什么意思，得看它前后的邻居**。我天天练'填空'，就是逼自己把前后文都读透。"

> **寓意**：BERT 的核心训练任务 MLM（掩码语言模型）就是"完形填空"——**盖住词，逼模型看前后文猜出来**，从而学会双向理解。这正是它比单向模型（如 GPT）更擅长"理解"任务的原因。

## 影响与遗产

- **预训练+微调成为标准**：几乎所有 NLP 模型沿用
- **双向编码器**：RoBERTa、ALBERT、DeBERTa 等继承者
- **任务大统一**：一个 BERT 适配分类、问答、NER 等任务
- **与 GPT 分道**：BERT 主"理解"，GPT 主"生成"

## 总结

**关键要点：**
1. BERT 只用编码器，实现双向理解
2. MLM（完形填空）+ NSP 两个预训练任务
3. 确立"预训练 + 微调"范式
4. 擅长理解类任务（分类、问答、NER）
