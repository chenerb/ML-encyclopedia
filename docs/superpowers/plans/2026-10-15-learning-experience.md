# 学习体验优化实施计划

> **For agentic workers:** 使用原生执行完成网站集成，并将独立的搜索、试卷和内容检查任务并行委派。所有变更留在当前工作区供审阅。

**Goal:** 在既有 GitHub Pages 网站中形成搜索、阅读、复习和测验的完整学习流程。

**Architecture:** 延续 Astro 静态生成；Markdown 链接由 rehype 插件转换，试卷为独立 content collection。浏览器交互拆分为搜索组件、学习状态纯函数和阅读组件。

**Tech Stack:** Astro 4、Tailwind、TypeScript、Node 内置 test、Python 标准库 unittest。

**Spec:** [在线学习体验优化](../specs/2026-10-15-learning-experience.md)

## 约束与复核重点

- 保留 `/ML-encyclopedia/` base 与既有网址；所有内部链接都应带 base。
- 课程只加载数字章节，排除内部设计文档。
- 不把滚动到底自动算作学会；完成由读者显式标记。
- localStorage 损坏或被禁用时仍可阅读，状态仅在当前设备浏览器保存。
- 无结果与网络故障分别呈现；手机和键盘均可完整操作。
