# 在线学习体验优化

用户要求进一步优化项目，选择“学习体验与项目质量”，并明确增强现有 GitHub Pages 网站的交互体验。

沿用 `web/` 的 Astro 与 Tailwind 静态站点、原有紫色视觉和部署地址。保留 Markdown 为内容来源，不复制正文，不引入账户与后端。交互数据仅保存在当前浏览器，并告知读者此范围。

交付范围：

- 正文相对 Markdown 链接在构建时按源文件解析，正确指向带项目 base 的站内页面；未提供网页的仓库文件链接到 GitHub。
- 67 篇正文和 94 套试卷建立可点击入口，题目和解析在网站内阅读，查看解析需要读者显式操作。
- 搜索覆盖全文，支持中文、多词、键盘上下选择、加载和错误重试；弹层正确管理焦点。
- 记录文章阅读位置，提供显式恢复入口与已学标记；首页显示真实学习进度和继续学习入口。
- 阅读目录跟随位置高亮；移动菜单、阅读控件支持键盘与减少动画偏好。
- 标准库内容检查、本地逻辑测试与生产构建进入 CI。修复已有断链及决策树示例语法错误。

验收：课程仍为67篇，所有本地链接和题解覆盖检查通过，搜索与进度逻辑测试通过，Astro 生产构建通过，浏览器核验搜索、阅读位置、完成标记、测验跳转和手机菜单。
