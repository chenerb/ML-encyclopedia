## 一、高难度选择题（每题 5 分，共 20 分）

**1.** 关于 Dropout 的本质，下列说法最**准确**的是？

- A. Dropout 是 L2 正则化的一个变体
- B. Dropout 近似于训练了指数级多个子网络的集成
- C. Dropout 通过降低学习率来防止过拟合
- D. Dropout 只能用在输出层

**2.** 关于梯度消失与梯度爆炸，下列说法**正确**的是？

- A. 梯度消失只发生在 Sigmoid 上，ReLU 对其完全免疫
- B. 两者根本原因都是链式法则中梯度的连乘
- C. 梯度爆炸一定意味着模型已经发散
- D. 残差连接会加剧梯度消失

**3.** 关于优化器，下列说法**正确**的是？

- A. Adam 的泛化能力一定比 SGD 更好
- B. Adam 为每个参数自适应学习率，SGD 使用统一学习率
- C. 动量系数越大越好
- D. Adam 完全不需要设置学习率

**4.** 关于 ReLU 激活函数，下列说法**正确**的是？

- A. ReLU 在 x = 0 处可导
- B. ReLU 在 x = 0 处不可导，但实践中仍可正常使用
- C. Sigmoid 的输出以 0 为中心
- D. tanh 完全不会出现梯度消失

## 二、复杂计算 / 推导题（每题 12 分，共 36 分）

**5.** 两层网络：x = 1，隐藏层 h = σ(w₁x)（σ 为 Sigmoid），输出层 ŷ = w₂·h（线性），损失 L = (ŷ − y)²。已知 w₁ = 0，w₂ = 1，y = 1。请通过前向传播 + 反向传播，计算 ∂L/∂w₁ 和 ∂L/∂w₂（提示：σ(0)=0.5，σ'(0)=0.25）。

**6.** 含 L2 正则化的损失 J(w) = (w − 3)² + λw²，λ = 0.5。求使 J(w) 最小的最优解 w\*，并说明正则化把最优解从何处"拉"向了 0。

**7.** 三层网络：h₁ = w₁x，h₂ = w₂h₁，ŷ = w₃h₂，损失 L = (ŷ − y)²。已知 x = 1，y = 0，w₁ = w₂ = w₃ = 1。请用链式法则求 ∂L/∂w₁（写出完整反向传播过程）。
