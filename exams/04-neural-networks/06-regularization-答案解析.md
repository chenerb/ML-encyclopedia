## 一、选择题

### 1. 答案：**B**

- **解析**：正则化通过惩罚模型复杂度，防止模型"死记硬背"训练数据，提升泛化能力。

### 2. 答案：**B**

- **解析**：L1 惩罚项 = λ·Σ|w|（权重的绝对值之和）。

### 3. 答案：**A**

- **解析**：L2 惩罚项 = λ·Σw²（权重的平方和）。

### 4. 答案：**B**

- **解析**：L1 的绝对值惩罚会让部分权重**恰好收敛到 0**，从而"删掉"不重要的特征，起到特征选择作用。L2 只是让权重整体变小、不归零。

### 5. 答案：**A**

- **解析**：Dropout 在训练时**随机丢弃部分神经元**，逼每个神经元都学到有用特征，防止对"明星神经元"的依赖。

### 6. 答案：**B**

- **解析**：早停监控**验证集**误差——验证误差一旦开始上升（过拟合苗头），就停止训练。若监控训练集，误差会一直下降，永远触发不了停止。

## 二、简单计算题

### 7. L2 正则化损失

```
L2 惩罚 = λ·Σw² = 0.1 × (1² + 2² + 3²) = 0.1 × 14 = 1.4

总损失 = 原始损失 + 惩罚 = 10 + 1.4 = 11.4
```

**答案：11.4**

### 8. L1 正则化损失

```
L1 惩罚 = λ·Σ|w| = 0.1 × (|1| + |2| + |3|) = 0.1 × 6 = 0.6

总损失 = 10 + 0.6 = 10.6
```

**答案：10.6**

> **对比**：同样权重下，L2 惩罚（1.4）大于 L1 惩罚（0.6），因为 L2 对大权重（如 3）惩罚更重（3²=9 vs |3|=3）。

## 三、中等计算题

### 9. 含 L2 正则的梯度

```
J(w) = (w − 2)² + λw²，λ = 0.5

∂J/∂w = 2(w − 2) + 2λw

w = 1 时：
∂J/∂w = 2×(1 − 2) + 2×0.5×1
       = 2×(−1) + 1
       = −2 + 1
       = −1
```

**答案：∂J/∂w = −1**

> **解释**：第一项 2(w−2) 是"拟合数据"的梯度，第二项 2λw 是"正则化"的梯度（把 w 往 0 拉）。两者方向相反时，正则化就起到了"刹车"作用。

### 10. 过拟合诊断与方案

**（1）现象：过拟合。** 训练误差 0.01（极低）但验证误差 0.5（很高），说明模型"背下"了训练数据，泛化能力差。

**（2）正则化方案（答出任意两种即可）：**

- **L2 正则（权重衰减）**：给损失加 λ·Σw²，惩罚大权重，逼模型"悠着点"
- **L1 正则（Lasso）**：让部分权重归零，自动做特征选择，简化模型
- **Dropout**：训练时随机丢弃神经元，降低对特定神经元的依赖
- **早停**：监控验证集误差，一开始上升就停止训练
- **数据增强**：给数据做变形（旋转、翻转、加噪），让模型见更多"变体"

> **易错点**：正则化是"防过拟合"，不是"治欠拟合"。如果训练误差本身很高（欠拟合），加正则化反而更糟。
