## 一、选择题

### 1. 答案：**C**

- **解析**：AND、OR、NOT 都是线性可分的，感知机能解决；**XOR** 的两类点呈"对角分布"，一条直线分不开，感知机无解。

### 2. 答案：**B**

- **解析**：MLP 拥有**隐藏层**，能层层组合特征，打破感知机的线性限制。

### 3. 答案：**A**

- **解析**：反向传播用**链式法则**，把总误差的梯度逐层往回传播。

### 4. 答案：**B**

- **解析**：梯度指向上升最快方向，要最小化损失，必须朝**负梯度**方向走。

### 5. 答案：**B**

- **解析**：ReLU 正半段导数恒为 1，能缓解 Sigmoid 两端的梯度消失问题。

### 6. 答案：**B**

- **解析**：训练误差极低、验证误差高，是**过拟合**的典型特征。

### 7. 答案：**B**

- **解析**：动量累积历史梯度，方向一致时加速、方向相反时抵消震荡。

### 8. 答案：**B**

- **解析**：激活函数引入非线性，让"深度"有意义。

### 9. 答案：**B**

- **解析**：L1 的绝对值惩罚会让部分权重恰好归零，起到特征选择作用；L2 只是整体收缩、不归零。

### 10. 答案：**A**

- **解析**：Adam = 动量（方向记忆）+ 自适应学习率（幅度记忆）。

## 二、简单计算题

### 11. 感知机前向计算

```
z = w·x + b = 1×2 + (−1)×1 + 0 = 1
```

z = 1 > 0，输出 1。

**答案：z = 1，输出 = 1**

### 12. σ(0)

```
σ(0) = 1/(1+e⁰) = 1/2 = 0.5
```

**答案：0.5**

### 13. 一步梯度下降

```
∇J = J'(w) = 2w = 2×2 = 4
w ← w − η·∇J = 2 − 0.5×4 = 0
```

**答案：w = 0**（恰好一步走到最小值）

### 14. ReLU(−5)

```
ReLU(−5) = max(0, −5) = 0
```

**答案：0**

## 三、中等计算题

### 15. 链式法则求梯度

```
前向：ŷ = w·x = 2×2 = 4，L = (4−1)² = 9

反向：
∂L/∂ŷ = 2(ŷ − y) = 2×(4−1) = 6
∂ŷ/∂w = x = 2

∂L/∂w = ∂L/∂ŷ × ∂ŷ/∂w = 6 × 2 = 12
```

**答案：∂L/∂w = 12**

### 16. 两层网络反向传播

```
前向：
h = w₁x = 1×1 = 1
ŷ = w₂h = 1×1 = 1
L = (1−0)² = 1

反向（从输出层往回）：
∂L/∂ŷ = 2(ŷ−y) = 2
∂L/∂w₂ = ∂L/∂ŷ × ∂ŷ/∂w₂ = 2 × h = 2
∂L/∂w₁ = ∂L/∂ŷ × ∂ŷ/∂h × ∂h/∂w₁ = 2 × w₂ × x = 2 × 1 × 1 = 2
```

**答案：∂L/∂w₁ = 2**

### 17. 学习率过大导致震荡

```
第 1 步：∇J = 2×1 = 2，w₁ = 1 − 1×2 = −1
第 2 步：∇J = 2×(−1) = −2，w₂ = −1 − 1×(−2) = 1
```

**答案：w 在 1 和 −1 之间来回震荡，无法收敛。**

**说明**：学习率 η=1 太大，一步跨过了最低点 w=0，冲到了对称另一侧；梯度方向每步翻转，参数永远在两侧弹跳。这正是"步子太大、来回震荡"的典型例子。

## 四、简答题

### 18. 神经网络训练循环

**参考答案：**

```
① 前向传播：输入逐层计算（z=Wx+b，过激活函数），得到预测输出
   → 作用：算出模型"当前的答案"

② 计算损失：用损失函数衡量预测值与真实值的差距
   → 作用：量化"错得有多离谱"

③ 反向传播：用链式法则把误差从输出层逐层往回传，算出每个参数的梯度
   → 作用：算出"每个参数该负多少责任"

④ 梯度下降更新：沿负梯度方向，按学习率调整参数（θ←θ−η·∇J）
   → 作用：让参数朝"误差变小"的方向挪动

重复 ①②③④，直到损失收敛。
```

> **点评**：这四步是理解一切深度学习训练的基础。前向"交卷"、损失"打分"、反向"追责"、梯度下降"改正"，循环往复，模型就"学会"了。
