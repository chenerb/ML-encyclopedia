## 一、高难度选择题

### 1. 答案：**B**

- **解析**：每次随机丢弃部分神经元，相当于训练一个"不同的子网络"；n 个神经元可组成 2ⁿ 种子网络，测试时相当于这些子网络**近似集成**（权重共享）。这是 Dropout 防过拟合的本质。
- **易错点**：Dropout 不是 L2 正则的变体（机制完全不同），也不只用于输出层。

### 2. 答案：**B**

- **解析**：梯度通过链式法则**连乘**传播——连乘的因子 >1 会爆炸，<1 会消失。这是两者的共同根源。
- **易错点**：A 错在 ReLU 负半段梯度为 0，也会"消失"（死神经元）；D 错在残差连接恰恰是**缓解**梯度消失的。

### 3. 答案：**B**

- **解析**：Adam 用二阶矩为**每个参数**自适应调整步长；SGD 所有参数共用一个学习率。
- **易错点**：A 错（某些 CV 任务 SGD+Momentum 泛化更好）；D 错（Adam 仍需设学习率，只是不敏感）。

### 4. 答案：**B**

- **解析**：ReLU 在 x=0 处左导数为 0、右导数为 1，**不可导**。但实践中该点测度为 0，且框架常约定 x=0 处导数为 0，因此仍可正常训练。
- **易错点**：C 错（Sigmoid 输出 (0,1) 不以 0 为中心，tanh 才以 0 为中心）；D 错（tanh 两端饱和仍会梯度消失）。

## 二、复杂计算 / 推导题

### 5. 带 Sigmoid 的两层反向传播

**前向传播：**

```
h = σ(w₁x) = σ(0×1) = σ(0) = 0.5
ŷ = w₂·h = 1×0.5 = 0.5
L = (ŷ − y)² = (0.5 − 1)² = 0.25
```

**反向传播（从输出层往回）：**

```
∂L/∂ŷ = 2(ŷ − y) = 2×(0.5 − 1) = −1

∂L/∂w₂ = ∂L/∂ŷ × ∂ŷ/∂w₂ = −1 × h = −1 × 0.5 = −0.5

∂L/∂w₁ = ∂L/∂ŷ × ∂ŷ/∂h × ∂h/∂w₁
        = −1 × w₂ × σ'(0) × x
        = −1 × 1 × 0.25 × 1
        = −0.25
```

**答案：∂L/∂w₁ = −0.25，∂L/∂w₂ = −0.5**

> **观察**：梯度 ∂L/∂w₁ 中乘了 σ'(0) = 0.25——这就是 Sigmoid 导致的梯度衰减。层数越多、σ' 越小，浅层梯度越微弱（梯度消失的雏形）。

### 6. L2 正则的最优解

```
J(w) = (w − 3)² + 0.5·w²

求导并令为零：
J'(w) = 2(w − 3) + 2×0.5×w = 2w − 6 + w = 3w − 6 = 0

⟹ w* = 2
```

**答案：w\* = 2**

**分析**：无正则时（λ=0），最优解是 w\* = 3（拟合数据的最优点）。加 L2 正则后，最优解被"拉"向 0，从 3 变成了 2——正则化项 2λw 像一个"弹簧"把 w 往原点拽。λ 越大，拉得越狠（λ→∞ 时 w\*→0）。

### 7. 三层网络反向传播

**前向传播：**

```
h₁ = w₁x = 1×1 = 1
h₂ = w₂h₁ = 1×1 = 1
ŷ = w₃h₂ = 1×1 = 1
L = (1 − 0)² = 1
```

**反向传播：**

```
∂L/∂ŷ = 2(ŷ − y) = 2

∂L/∂w₃ = ∂L/∂ŷ × ∂ŷ/∂w₃ = 2 × h₂ = 2

∂L/∂w₂ = ∂L/∂ŷ × ∂ŷ/∂h₂ × ∂h₂/∂w₂ = 2 × w₃ × h₁ = 2 × 1 × 1 = 2

∂L/∂w₁ = ∂L/∂ŷ × ∂ŷ/∂h₂ × ∂h₂/∂h₁ × ∂h₁/∂w₁
        = 2 × w₃ × w₂ × x
        = 2 × 1 × 1 × 1 = 2
```

**答案：∂L/∂w₁ = 2**

> **要点**：误差 ∂L/∂ŷ = 2 沿着 w₃ → w₂ → x 一路"传"回输入层，每经过一层乘一个权重。这就是"误差逐层回传"的完整体现。

## 三、证明题

### 8. 证明 σ'(z) = σ(z)(1 − σ(z))

```
σ(z) = 1/(1 + e⁻ᶻ)

σ'(z) = −(1+e⁻ᶻ)⁻² · (−e⁻ᶻ)
      = e⁻ᶻ / (1+e⁻ᶻ)²
      = [1/(1+e⁻ᶻ)] · [e⁻ᶻ/(1+e⁻ᶻ)]
      = σ(z) · [(1+e⁻ᶻ−1)/(1+e⁻ᶻ)]
      = σ(z) · [1 − 1/(1+e⁻ᶻ)]
      = σ(z) · (1 − σ(z))   ✓
```

**结论：σ'(z) = σ(z)(1 − σ(z))**，其最大值为 σ'(0) = 0.25。

### 9. 证明线性网络退化为单层

设网络有 L 层，每层都是线性变换（无激活或线性激活）：

```
h₁ = W₁x + b₁
h₂ = W₂h₁ + b₂
...
ŷ = W_L·h_{L−1} + b_L
```

逐层代入，最终：

```
ŷ = W_L(W_{L−1}(...(W₁x + b₁)...) + b_{L−1}) + b_L
  = (W_L·W_{L−1}·...·W₁)·x + (合并的常数项)
  = W'x + b'
```

其中 W' = W_L·W_{L−1}·...·W₁ 仍是一个矩阵，b' 是合并后的偏置向量。

**结论**：L 层线性变换的复合 = **一个**线性变换。无论叠多少层，都等价于单层线性模型，表达能力没有提升。

> **推论**：**非线性激活函数是"深度"有意义的前提**。这正是 ReLU 等激活函数不可或缺的根本原因。

## 四、开放应用题

### 10. 训练不收敛的排查

**可能原因与方案（答出任意 4 种即满分）：**

1. **学习率过大**：损失震荡或发散
   → 排查：画损失曲线观察；方案：降低学习率，或用学习率衰减/warmup

2. **学习率过小**：损失下降极慢
   → 方案：适当增大学习率，或换 Adam（自适应步长）

3. **梯度消失**：深层 + Sigmoid/tanh 导致浅层收不到信号
   → 方案：换 ReLU、加 BatchNorm、用残差连接

4. **梯度爆炸**：损失突然变 NaN
   → 方案：梯度裁剪（Gradient Clipping）、降低学习率

5. **数据未标准化**：量纲差异大，损失地形病态
   → 方案：对特征做标准化（StandardScaler）

6. **权重初始化不当**：初始值全 0 或过大导致对称/饱和
   → 方案：用 Xavier/He 初始化

7. **标签或数据有问题**：标签错误、数据泄漏、类别不平衡
   → 方案：检查数据质量、可视化样本

> **评分要点**：能区分"学习率大 vs 小""消失 vs 爆炸"这两对容易混淆的问题，并给出对应的排查手段，即为高分答案。
