## 一、选择题（每题 5 分，共 50 分）

**1.** 单层感知机无法解决下列哪个问题？

- A. 与（AND）逻辑
- B. 或（OR）逻辑
- C. 异或（XOR）逻辑
- D. 非（NOT）逻辑

**2.** 多层感知机（MLP）与单层感知机最关键的差别是？

- A. 使用不同的激活函数
- B. 拥有隐藏层
- C. 使用 GPU 训练
- D. 能输出概率

**3.** 反向传播算法的数学核心是？

- A. 链式法则
- B. 贝叶斯定理
- C. 泰勒展开
- D. 奇异值分解

**4.** 梯度下降更新参数时，应朝哪个方向走？

- A. 梯度方向（上升最快方向）
- B. 负梯度方向（下降最快方向）
- C. 任意随机方向
- D. 与梯度垂直的方向

**5.** ReLU 相比 Sigmoid 在隐藏层中的主要优势是？

- A. 能输出概率
- B. 缓解梯度消失问题
- C. 输出范围更大
- D. 计算更复杂、更精确

**6.** 某模型训练误差 0.01、验证误差 0.5，这最可能是？

- A. 欠拟合
- B. 过拟合
- C. 训练数据太少
- D. 学习率过大

**7.** 优化器中"动量（Momentum）"的主要作用是？

- A. 减小更新步长
- B. 累积历史梯度，减少震荡、加速前进
- C. 增加随机性
- D. 降低学习率

**8.** 激活函数在神经网络中的核心作用是？

- A. 加快计算
- B. 引入非线性
- C. 减少参数
- D. 存储数据

**9.** 如果希望正则化同时起到"特征选择"（让部分权重归零）的作用，应选择？

- A. L2 正则化
- B. L1 正则化
- C. Dropout
- D. 早停

**10.** Adam 优化器结合了哪两大机制？

- A. 动量 + 自适应学习率
- B. 正则化 + Dropout
- C. 批归一化 + 残差连接
- D. 早停 + 数据增强

## 二、简单计算题（每题 6 分，共 24 分）

**11.** 某感知机权重 w = (1, −1)，偏置 b = 0，输入 x = (2, 1)。请计算加权和 z 及输出（阶跃函数：z>0 输出 1）。

**12.** 计算 Sigmoid 函数在 z = 0 处的值 σ(0)。

**13.** 函数 J(w) = w²，当前 w = 2，学习率 η = 0.5，执行一步梯度下降，求新的 w。

**14.** 计算 ReLU(−5) 的值。

## 三、中等计算题（每题 7 分，共 21 分）

**15.** 已知损失 L = (ŷ − y)²，ŷ = w·x，其中 y = 1，w = 2，x = 2。请用链式法则求 ∂L/∂w。

**16.** 两层网络：h = w₁x，ŷ = w₂h，L = (ŷ − y)²。已知 x = 1，y = 0，w₁ = 1，w₂ = 1。请计算 ∂L/∂w₁（写出反向传播过程）。

**17.** 函数 J(w) = w²，从 w₀ = 1 出发，学习率 η = 1，执行两步梯度下降，观察 w 的变化，并说明发生了什么问题。
