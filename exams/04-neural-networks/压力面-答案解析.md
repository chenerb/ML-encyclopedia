## Q1. 万能近似定理说了什么，没说什么

**参考答案**：
万能近似定理说：**只要隐藏层足够宽、使用非线性激活，单隐层 MLP 就能以任意精度逼近任意连续函数**（在有界闭区间上）。

但它**没说**：
- **能逼近 ≠ 能学会**：如何找到那些参数（训练算法）是另一回事
- **没说需要多宽**：可能宽到天文数字，实际不可行
- **没说泛化能力**：逼近的是"训练数据"，不一定泛化到新数据
- **没说"深"的必要**：单隐层理论上就够，但实践中"深"往往比"宽"更高效

**追问**："那为什么还要深度学习（很多层），单隐层不是够了吗？"
因为实践上，深层网络用**指数级更少的参数**就能达到相同表达能力，且逐层学到的特征层次更符合数据的内在结构（边→形状→部件→整体）。

**踩坑点**：把"能逼近"误当成"能学会、能泛化"，是对该定理最常见的误解。

## Q2. 反向传播在"传播"什么

**参考答案**：传播的是**误差对每个参数的梯度**（责任）。

前向传播从输入算到输出，得到预测误差；反向传播从输出层的误差出发，用链式法则把这个误差**逐层往回"分摊"**——每经过一层，就计算出"这一层的每个参数对最终误差该负多少责任"（梯度）。就像接力赛输了，教练从最后一棒逐棒倒推谁交接慢了。

**追问**："为什么不是正向算每个参数的梯度？"
正向逐个扰动参数（数值法）需要 O(参数数量²) 的计算量，而反向传播一次就能算出**所有**参数的梯度，效率高几个数量级，这是它能支撑深度学习的关键。

**踩坑点**：答成"传播误差值"而非"传播梯度"，概念不清。

## Q3. 局部最优在深度学习里严重吗

**参考答案**：**没想象中那么严重**。

- 早期担心：高维损失函数有很多"坑"，梯度下降会卡在局部最优
- 现实：高维空间中，"局部最优"往往几乎不存在——真正的陷阱是**鞍点**（梯度为 0 但既非极大也非极小），而非局部最优
- 且现代技术（随机梯度噪声、动量、自适应学习率、好的初始化）都能帮模型"冲过"鞍点

**追问**："那什么时候局部最优才真的麻烦？"
低维、凸性差的经典优化问题里才需要担心；深度学习中，更值得关注的是**梯度消失、过拟合、优化不稳定**，而非局部最优。

**踩坑点**：张口就"容易卡在局部最优"，暴露的是没跟进现代研究结论。

## Q4. Sigmoid 到底"死"在哪

**参考答案**：
Sigmoid 三大问题：
1. **梯度消失**：导数最大才 0.25，深层连乘后梯度趋近 0，浅层训不动
2. **输出不以 0 为中心**：输出全为正，导致梯度更新"锯齿状"震荡、收敛慢
3. **指数运算慢**：相比 ReLU 的 max 操作

ReLU 正半段梯度恒为 1、计算极快、稀疏激活，完美解决前两点，所以成为默认。

**追问**："ReLU 就完美了吗？"
不。负半段梯度为 0 导致"死亡 ReLU"，输出也不以 0 为中心，所以又有 Leaky ReLU、ELU、GELU 等改进。

**踩坑点**：只说"梯度消失"，漏掉"不以 0 为中心"，理解不完整。

## Q5. 死亡 ReLU 的排查与解决

**参考答案**：
死亡 ReLU = 某神经元的输入恒为负，输出恒为 0，梯度恒为 0，参数永久停更。

**排查**：训练后统计每层输出为 0 的神经元比例，若某层大量（如 >50%）"死掉"，即中招。

**解决**：
- **换 Leaky ReLU / PReLU**：负半段给一个小斜率（如 0.01），保留梯度
- **降低学习率**：学习率过大是主要诱因
- **用更好的初始化**（He 初始化）
- **加 BatchNorm**：让输入分布更稳定，避免长期为负

**追问**："死亡 ReLU 和梯度消失是一回事吗？"
相关但不完全等同：死亡 ReLU 是"局部神经元永久失效"，梯度消失是"整体梯度随层数衰减"。前者是 ReLU 的专属问题，后者是链式法则的普遍问题。

**踩坑点**：说不出排查手段（统计死神经元比例），只会背"换 Leaky ReLU"。

## Q6. 学习率怎么调，warmup 是什么

**参考答案**：
- 从小学习率试起（0.1 → 0.01 → 0.001 对数搜索）
- 观察损失曲线：震荡/发散 → 调小；下降太慢 → 调大
- 配合**学习率衰减**：前期大步、后期小步，帮助收敛到更优解

**warmup（学习率热身）**：训练开始的前若干步，学习率从很小**线性/指数增长**到目标值，再正常衰减。目的：模型初始参数是随机的，若一开始就用大学习率，梯度大且方向不可靠，容易让训练"崩掉"；先用小学习率"热身"几轮，等模型找到稳定方向再提速。

**追问**："为什么大模型（如 Transformer）几乎必用 warmup？"
因为大模型训练极不稳定，初始大学习率 + 深层结构极易导致梯度爆炸/震荡，warmup 是稳定训练的标配。

**踩坑点**：把 warmup 理解成"先小后大再小"却说不清"为什么先小"，或完全没听过。

## Q7. Dropout 训练与测试的差异

**参考答案**：
- **训练时**：以概率 p 随机丢弃神经元（置 0），每次前向都在一个"不同"的子网络上进行
- **测试时**：**不丢弃**任何神经元，使用完整网络；但由于训练时每个神经元以概率 p 被丢弃，输出期望被缩小了 (1−p) 倍，所以测试时要把输出（或权重）**乘以 (1−p) 做缩放补偿**

**追问**："缩放补偿具体乘在哪？"
两种等价做法：①测试时输出乘 (1−p)；②训练时保留的神经元输出除以 (1−p)（倒置 Dropout），测试时则什么都不用做——后者更常用。

**踩坑点**：知道"训练丢、测试不丢"，但漏掉"缩放补偿"，是典型的"只知其一不知其二"。

## Q8. 梯度消失的多种解法

**参考答案**（至少三个）：
1. **换激活函数**：ReLU 及其变体（正半段梯度恒 1）
2. **残差连接（ResNet）**：让梯度走"捷径"直通浅层，不经过多层衰减
3. **批归一化（BatchNorm）**：稳定每层输入分布，避免落入饱和区
4. **好的初始化**：Xavier/He 初始化，让各层方差一致
5. **梯度裁剪**（针对梯度爆炸）、**更浅的网络**

**追问**："残差连接为什么能治梯度消失？"
残差块输出 = F(x) + x，求导后梯度 = ∂F/∂x + 1，那个"+1"保证梯度至少能"原样"传回浅层，不会被连乘衰减到 0。

**踩坑点**：只会说"换 ReLU"，缺乏知识广度。

## Q9. 什么时候放弃 Adam 用 SGD+Momentum

**参考答案**：
- **CV 任务**（图像分类、目标检测）中，精心调参的 **SGD+Momentum** 泛化效果常优于 Adam
- 当你发现 Adam 收敛快但**验证集/测试集泛化不如预期**时，可试 SGD+Momentum
- 需要**更可复现、更稳定**的训练时，SGD 的行为更可控

**追问**："为什么 Adam 泛化有时反而差？"
Adam 的自适应步长会让模型"太贴合"训练集的几何结构，可能收敛到更尖锐的极小值，泛化略差；SGD 的均匀步长倾向收敛到更平坦的极小值，泛化更好。

**踩坑点**：盲目"Adam 万能"或"Adam 一定差"，说不出具体取舍依据。

## Q10. loss 变 NaN 的排查

**参考答案**（常见原因）：
1. **学习率过大**：参数更新一步飞出去，损失爆炸 → 降低学习率
2. **梯度爆炸**：深层网络梯度连乘失控 → 梯度裁剪
3. **数据有异常**：数据里出现 inf/NaN，或标签非法 → 检查数据清洗
4. **数值溢出**：softmax/指数运算溢出 → softmax 前减最大值、用 logsumexp
5. **损失函数本身**：log(0) 之类 → 加 eps 平滑（如交叉熵加 1e−8）

**排查顺序**：先看 loss 是"突然 NaN"还是"一开始就 NaN"——前者多因学习率/梯度爆炸，后者多因数据/数值问题。

**踩坑点**：只会说"降低学习率"，不会系统排查，缺乏工程经验。

## Q11. 层数越深一定越好吗

**参考答案**：**不是**。

- 深度增加能提升表达能力，但也带来**梯度消失/爆炸、过拟合、优化困难、计算开销**等问题
- 数据少、任务简单时，深层网络反而过拟合；数据多、任务复杂时，深度才有明显收益
- 实践中存在"最优深度"，需要靠实验/交叉验证确定，而非"越深越好"

**追问**："为什么 ResNet 能做到 152 层还更好？"
因为它用残差连接 + BatchNorm 解决了深层网络的梯度消失问题，让"深度"的红利得以兑现。没有这些技术，盲目加深只会训不动。

**踩坑点**：答"越深越好"，是没理解深度与优化难度的权衡。

## Q12. 防过拟合"三件套"怎么组合

**参考答案**：
- **L2 正则（权重衰减）**：几乎所有场景的"标配"，给大权重扣分，成本低、收益稳定
- **Dropout**：**大网络、全连接层**场景效果好（神经元多、易过拟合时），CNN 中也可用在 FC 层；小网络慎用（可能欠拟合）
- **早停**：**零成本**的兜底手段，监控验证集，几乎总是开启

**组合策略**：通常 **L2 + 早停** 打底，网络大/数据少时**再加 Dropout**。三者可叠加，但要防止"正则过度"导致欠拟合。

**追问**："数据增强算不算正则化？"
算，而且是效果最好的一种——通过扩充"变体"数据提升泛化，图像任务尤其依赖它。

**踩坑点**：说不出各自的"适用边界"，只会堆砌名词。
