## 一、选择题

### 1. 答案：**B**

- **解析**：激活函数引入**非线性**，让多层网络能拟合复杂函数。没有它，多层线性网络退化为单层。

### 2. 答案：**A**

- **解析**：ReLU(z) = max(0, z)——正数原样输出，负数直接输出 0。

### 3. 答案：**B**

- **解析**：Sigmoid 输出严格落在 (0, 1) 开区间。tanh 才是 (−1, 1)。

### 4. 答案：**C**

- **解析**：Softmax 把一组分数转换成"加起来等于 1"的概率分布，是多分类输出层的标准选择。

### 5. 答案：**B**

- **解析**：ReLU 简单高效、缓解梯度消失，是隐藏层的默认选择。

### 6. 答案：**B**

- **解析**：当 ReLU 的输入恒为负时，输出恒为 0、梯度恒为 0，该神经元"死掉"，参数再也无法更新。学习率过大容易诱发此问题，可用 Leaky ReLU 缓解。

## 二、简单计算题

### 7. ReLU 计算

```
ReLU(3)  = max(0, 3)  = 3
ReLU(−3) = max(0, −3) = 0
```

**答案：ReLU(3) = 3，ReLU(−3) = 0**

### 8. 零点处的值

```
σ(0) = 1/(1+e⁰) = 1/2 = 0.5
tanh(0) = 0
```

**答案：σ(0) = 0.5，tanh(0) = 0**

## 三、中等计算题

### 9. Softmax 计算

```
softmax(zᵢ) = e^(zᵢ) / Σ e^(zⱼ)

e¹ = 2.718
e² = 7.389
e³ = 20.086

Σ = 2.718 + 7.389 + 20.086 = 30.193

softmax(1) = 2.718 / 30.193 ≈ 0.090
softmax(2) = 7.389 / 30.193 ≈ 0.245
softmax(3) = 20.086 / 30.193 ≈ 0.665
```

**答案：三个类别的概率约为 (0.090, 0.245, 0.665)**

> **验证**：0.090 + 0.245 + 0.665 = 1.000 ✓，且分数最高的 z=3 对应概率最大（0.665）。

### 10. Sigmoid 梯度消失 vs ReLU 缓解

**Sigmoid 的问题：**

```
σ'(z) = σ(z)(1 − σ(z))，最大值为 0.25（在 z=0 处）
```

反向传播时梯度每穿过一层 Sigmoid 就乘以一次 ≤0.25 的导数。深层网络中：

```
梯度 ≈ 0.25 × 0.25 × ... × 0.25（连乘）
```

几十层后梯度指数级衰减到接近 0，浅层参数几乎无法更新 → **梯度消失**。

**ReLU 的缓解：**

```
ReLU'(z) = 1（当 z > 0），0（当 z < 0）
```

正半段导数**恒为 1**，梯度穿过 ReLU 时不会衰减（只要输入为正）。因此深层网络中梯度能"原样"传回浅层，避免了指数级衰减。

> **补充**：ReLU 负半段导数为 0 会带来"死亡 ReLU"问题，但整体上它让深层网络训练成为可能，是深度学习爆发的关键推手之一。
