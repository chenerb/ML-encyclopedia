## 一、选择题

### 1. 答案：**B**

- **解析**：梯度指向**函数值上升最快**的方向。因此要"下山"（最小化），必须朝梯度的**反方向**走。

### 2. 答案：**B**

- **解析**：梯度下降更新公式为 `θ ← θ − η·∇J`——沿负梯度方向迈一步，步长由学习率 η 控制。

### 3. 答案：**B**

- **解析**：学习率太大，一步跨过谷底，会在最低点两侧来回震荡，甚至"飞出去"（发散）。

### 4. 答案：**C**

- **解析**：小批量梯度下降每次用一小批样本算梯度，兼顾批量（稳定）和随机（快）的优点，是实践中最常用的。

### 5. 答案：**B**

- **解析**：梯度下降只保证找到**局部最优**，不保证全局最优。地形有很多坑时，可能走进浅坑就停住。

### 6. 答案：**A**

- **解析**：量纲不同会扭曲"地形"（一个方向极陡、一个方向极平），标准化让地形均匀，梯度下降收敛更快更稳。

## 二、简单计算题

### 7. 一步梯度下降

```
J(w) = w²，梯度 ∇J = J'(w) = 2w

当前 w = 3：
∇J = 2×3 = 6

w ← w − η·∇J = 3 − 0.1×6 = 3 − 0.6 = 2.4
```

**答案：w = 2.4**

### 8. 第二步

```
当前 w = 2.4：
∇J = 2×2.4 = 4.8

w ← 2.4 − 0.1×4.8 = 2.4 − 0.48 = 1.92
```

**答案：w = 1.92**

## 三、中等计算题

### 9. 三步迭代观察收敛

```
第 0 步：w₀ = 3
第 1 步：∇J = 2×3 = 6，w₁ = 3 − 0.6 = 2.4
第 2 步：∇J = 2×2.4 = 4.8，w₂ = 2.4 − 0.48 = 1.92
第 3 步：∇J = 2×1.92 = 3.84，w₃ = 1.92 − 0.384 = 1.536
```

**观察**：3 → 2.4 → 1.92 → 1.536，w 单调递减、逐步逼近最小值 w = 0。

**答案：w₁ = 2.4，w₂ = 1.92，w₃ = 1.536，正在向最小值收敛 ✓**

### 10. 学习率过大导致震荡

```
第 1 步：∇J = 2×3 = 6，w₁ = 3 − 1×6 = −3
第 2 步：∇J = 2×(−3) = −6，w₂ = −3 − 1×(−6) = 3
```

**观察**：w 在 3 和 −3 之间**来回震荡**，一步都没向最小值 w = 0 靠近。

**原因**：学习率 η = 1 太大，一步就"跨过"了整个抛物线的最低点，冲到了对称的另一侧。因为梯度方向每步翻转，参数永远在两侧弹跳，**无法收敛**。

> **结论**：这就是"步子太大、来回震荡"的典型例子。对 J(w)=w² 这类函数，η 需小于某个阈值才能收敛；η 越大收敛越快，但超过阈值就会震荡甚至发散。
