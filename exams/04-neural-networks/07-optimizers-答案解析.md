## 一、选择题

### 1. 答案：**A**

- **解析**：优化器是梯度下降的进化版，解决"如何更聪明地更新参数"——加惯性、调步长，更快更稳地到达最低点。

### 2. 答案：**B**

- **解析**：动量累积历史梯度（像滚雪球），方向一致时加速，方向相反时抵消震荡，让下降更稳更快。

### 3. 答案：**B**

- **解析**：自适应学习率根据历史梯度幅度，为每个参数自动调步长——陡坡收步、平坡迈大步。

### 4. 答案：**A**

- **解析**：Adam = 动量（一阶矩，方向记忆）+ 自适应学习率（二阶矩，幅度记忆）。

### 5. 答案：**C**

- **解析**：Adam 论文推荐的默认学习率是 **0.001**，多数场景开箱即用。

### 6. 答案：**B**

- **解析**：某些 CV 任务（图像分类、目标检测）中，精心调参的 **SGD + Momentum** 泛化效果常优于 Adam。Adam 则更适合 NLP、Transformer 等。

## 二、简单计算题

### 7. 裸 SGD 一步

```
θ ← θ − η·g = 10 − 0.1×2 = 9.8
```

**答案：θ = 9.8**

### 8. 动量 SGD 一步

```
v ← β·v + g = 0.9×0 + 2 = 2
θ ← θ − η·v = 10 − 0.1×2 = 9.8
```

**答案：θ = 9.8，v = 2**

> **说明**：第一步两者结果相同（因为初始速度为 0），差异从第二步开始显现。

## 三、中等计算题

### 9. SGD vs 动量两步对比

**裸 SGD：**

```
第 1 步：θ₁ = 10 − 0.1×2 = 9.8
第 2 步：θ₂ = 9.8 − 0.1×2 = 9.6
```

**带动量 SGD：**

```
第 1 步：v₁ = 0.9×0 + 2 = 2，θ₁ = 10 − 0.1×2 = 9.8
第 2 步：v₂ = 0.9×2 + 2 = 1.8 + 2 = 3.8，θ₂ = 9.8 − 0.1×3.8 = 9.42
```

**对比：**

```
裸 SGD 两步后：θ = 9.6
动量法两步后：θ = 9.42
```

**答案**：裸 SGD 后 θ = 9.6，动量法后 θ = 9.42。

**动量优势**：当梯度方向持续一致时，动量会**累积速度**（v 从 2 涨到 3.8），第二步迈的步子更大，下降更快。若梯度方向来回震荡，动量则会互相抵消、抑制震荡。这就是"滚雪球"效应。

### 10. Adam 为何"开箱即用"

**两大机制的结合：**

**① 动量（一阶矩估计 m）：**

```
m ← β₁·m + (1−β₁)·g
```

像滚雪球，累积梯度的"方向记忆"，减少震荡、加速一致方向上的前进。

**② 自适应学习率（二阶矩估计 v）：**

```
v ← β₂·v + (1−β₂)·g²
θ ← θ − η·m/(√v + ε)
```

用梯度平方的累积估计每个参数的"波动幅度"，自动为每个参数调整有效步长——梯度大的参数步长变小（防震荡），梯度小的参数步长变大（加速）。

**为何"开箱即用"：**

- 对学习率不敏感（默认 0.001 大多可用）
- 自动处理不同参数的尺度差异
- 无需像 SGD 那样精心调学习率调度

**代价**：某些任务（尤其 CV）中，Adam 的泛化略逊于精心调参的 SGD+Momentum，此时可换用后者。
