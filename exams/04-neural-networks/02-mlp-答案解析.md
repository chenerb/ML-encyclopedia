## 一、选择题

### 1. 答案：**B**

- **解析**：MLP 拥有**隐藏层**，能把特征层层组合，打破感知机"只会画直线"的限制。

### 2. 答案：**B**

- **解析**：线性变换的复合仍是线性变换，所以多层线性网络等价于单层线性模型，层数再多也白搭。

### 3. 答案：**B**

- **解析**：万能近似定理指出，只要隐藏层足够宽，MLP 理论上能逼近任意连续函数。但"能逼近"不等于"能学会"——如何训练是另一回事。

### 4. 答案：**B**

- **解析**：隐藏层把简单特征逐层组合成复杂特征（边 → 形状 → 部件 → 整体），这是"深度"的意义所在。

### 5. 答案：**A**

- **解析**：权重矩阵形状为 **(输入维度 × 输出维度)**。输入层 3 维 → 隐藏层 5 个神经元，所以是 3 × 5。

### 6. 答案：**B**

- **解析**：ReLU 正半段梯度恒为 1，能**缓解梯度消失**；Sigmoid 两端饱和、梯度趋近 0。这是 ReLU 成为深度网络默认激活的主因。

## 二、简单计算题

### 7. 前向传播（线性激活）

```
h = σ(W₁x + b₁) = W₁x + b₁   （线性激活 σ(z)=z）

W₁x = [[1,1],[2,0]] · [1,2]
    = [1×1 + 1×2,  2×1 + 0×2]
    = [3, 2]

h = (3, 2) + (0, 0) = (3, 2)
```

**答案：h = (3, 2)**

### 8. 参数量计算

```
第一层（3→4）：权重 3×4 = 12，偏置 4 → 共 16
第二层（4→1）：权重 4×1 = 4，偏置 1 → 共 5

总参数量 = 16 + 5 = 21
```

**答案：21 个参数**

> **提示**：别忘算偏置！偏置也是参数。

## 三、中等计算题

### 9. 带 ReLU 的两层前向传播

**第一步：计算隐藏层线性输出**

```
z₁ = W₁x + b₁ = [[1,0],[0,1]] · [1,-1] + (0,0) = [1, -1]
```

**第二步：过 ReLU 激活**

```
h = ReLU(z₁) = (max(0,1), max(0,-1)) = (1, 0)
```

**第三步：输出层**

```
ŷ = W₂·h + b₂ = [1,1]·[1,0] + 0 = 1 + 0 = 1
```

**答案：ŷ = 1**

> **关键点**：ReLU 把 -1 变成了 0，这是非线性的体现。如果没有 ReLU，h 就是 (1, -1)，最终 ŷ = 1 + (-1) = 0，结果完全不同。

### 10. 线性复合退化的数学证明

设两层都是线性变换（无激活）：

```
第一层：h = W₁x + b₁
第二层：ŷ = W₂h + b₂
```

把第一层代入第二层：

```
ŷ = W₂(W₁x + b₁) + b₂
  = (W₂W₁)x + (W₂b₁ + b₂)
  = W'x + b'
```

其中 W' = W₂W₁，b' = W₂b₁ + b₂。

**结论**：两个线性变换的复合仍然是**一个**线性变换（可以写成一个矩阵 W'）。无论叠多少层，只要都是线性的，最终都能合并成一层线性模型。因此：

> **没有非线性激活，深度就毫无意义**——多层线性网络永远等价于单层线性模型，学不会任何非线性关系。
