## 一、选择题

### 1. 答案：**B**

- **解析**：反向传播的核心是**链式法则**——把"总误差对某参数的梯度"分解成一连串局部梯度的乘积，从输出层一路乘回输入层。

### 2. 答案：**B**

- **解析**：前向传播从输入算到输出（得到预测值和损失）；反向传播从损失出发，逐层往回算每个参数的**梯度**。

### 3. 答案：**B**

- **解析**：1986 年 **Rumelhart、Hinton、Williams** 在《自然》发表论文推广反向传播，让多层网络可训练，神经网络由此复兴。

### 4. 答案：**A**

- **解析**：梯度 ∂L/∂w 表示"参数 w 微小变化时，损失 L 会变化多少"，即**损失对该参数的敏感度**。

### 5. 答案：**A**

- **解析**：梯度通过链式法则**连乘**传播。当很多因子都小于 1 时（如 Sigmoid 导数），连乘结果会指数级趋近 0，导致浅层参数几乎无法更新——这就是梯度消失。

### 6. 答案：**B**

- **解析**：分工明确——**反向传播算梯度**（"每个参数该负多少责任"），**梯度下降用梯度更新参数**（"往哪走、走多远"）。两者配合构成完整训练循环。

## 二、简单计算题

### 7. 链式法则

```
dz/dx = dz/dy × dy/dx = 3 × 2 = 6
```

**答案：6**

### 8. 单参数梯度

```
∂L/∂w = ∂L/∂ŷ × ∂ŷ/∂w

∂L/∂ŷ = 2(ŷ − y) = 2×(1×3 − 2) = 2×1 = 2
∂ŷ/∂w = x = 3

∂L/∂w = 2 × 3 = 6
```

**答案：∂L/∂w = 6**

> **提示**：先算"输出层对损失的敏感度"∂L/∂ŷ，再乘"输出对参数的敏感度"∂ŷ/∂w，这就是反向传播的基本节奏。

## 三、中等计算题

### 9. 两层网络梯度

**前向传播：**

```
h = w₁x = 1×1 = 1
ŷ = w₂h = 1×1 = 1
L = (ŷ − y)² = (1 − 0)² = 1
```

**反向传播（从输出层往回）：**

```
∂L/∂ŷ = 2(ŷ − y) = 2×(1 − 0) = 2

∂L/∂w₂ = ∂L/∂ŷ × ∂ŷ/∂w₂ = 2 × h = 2 × 1 = 2

∂L/∂w₁ = ∂L/∂ŷ × ∂ŷ/∂h × ∂h/∂w₁
        = 2 × w₂ × x
        = 2 × 1 × 1 = 2
```

**答案：∂L/∂w₁ = 2，∂L/∂w₂ = 2**

> **关键观察**：∂L/∂w₁ 的计算中，误差"穿过"了 w₂ 和 x 两层，这正是"误差逐层往回传"的体现。

### 10. Sigmoid 导致梯度消失的机制

**Sigmoid 的导数：**

```
σ'(z) = σ(z)(1 − σ(z))
```

其**最大值**出现在 z = 0 处：σ'(0) = 0.5 × 0.5 = **0.25**。

**连乘效应：**

反向传播时，梯度每穿过一层 Sigmoid，就要乘以一次 σ'(z) ≤ 0.25：

```
梯度 ≈ 0.25 × 0.25 × 0.25 × ...（每层乘一次）
```

- 10 层：0.25¹⁰ ≈ 0.000001（几乎为零）
- 20 层：0.25²⁰ ≈ 10⁻¹²（彻底消失）

**结论**：梯度经过多层 Sigmoid 后指数级衰减到接近 0，浅层参数几乎收不到"更新信号"，网络训不动。这就是**梯度消失**。

**解决方向**：换用 ReLU（正半段导数恒为 1）、残差连接（ResNet）、BatchNorm 等。
