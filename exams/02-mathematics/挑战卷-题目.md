# 第二章 · 数学基础 挑战卷

> 难度：⭐⭐⭐⭐
> 建议用时：60 分钟 ｜ 满分：100 分

## 一、高难度选择题（每题 10 分，共 50 分）

**1.** 关于矩阵 A(m×n) 与 B(p×q)，下列说法**严格成立**的是？

- A. A·B 与 B·A 都总有定义
- B. 若 n=p，则 A·B 有定义，结果为 m×q
- C. Aᵀ 的形状是 (n, m)
- D. B 和 C 都对

**2.** 关于贝叶斯定理 P(A|B) = P(B|A)P(A)/P(B)，下列说法**错误**的是？

- A. P(A) 是先验概率
- B. P(A|B) 是后验概率
- C. P(B) 是证据（全概率）
- D. 分母 P(B) 可以省略不算

**3.** 关于梯度与梯度下降，下列说法**正确**的是？

- A. 梯度是标量
- B. 沿负梯度方向更新能最快减小函数值
- C. 学习率越大收敛越快，无副作用
- D. 梯度下降只适用于凸函数

**4.** 关于损失函数与优化，下列说法**错误**的是？

- A. 均方误差是损失函数
- B. 交叉熵也是损失函数
- C. 所有损失函数都是凸函数
- D. 优化目标是让损失最小

**5.** 向量 x 和 y 的点积 x·y = 0 说明？

- A. 两向量方向相同
- B. 两向量垂直（正交）
- C. 两向量平行
- D. 两向量无关且不垂直

## 二、计算/推导题（每题 25 分，共 50 分）

**6.** 已知 f(x) = (x² + 1)²，请用链式法则求 f'(x)，并计算 f'(1)。

**7.** 已知损失 L = (ŷ − y)²，ŷ = σ(w·x)，σ(z) = 1/(1+e⁻ᶻ)（Sigmoid）。请写出 ∂L/∂w 的表达式（提示：用链式法则，σ'(z)=σ(z)(1−σ(z))），并说明它与"线性回归梯度"的区别。
