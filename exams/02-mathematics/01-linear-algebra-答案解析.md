## 二、计算题

### 7. A·x

```
A·x = [[1,2],[3,4]] · [1,1]
    = [1×1 + 2×1,  3×1 + 4×1]
    = [3, 7]
```

**答案：A·x = [3, 7]**

### 8. 线性回归的矩阵形式

```
X：m×n 矩阵（m 个样本，n 个特征）
w：n×1 向量（权重）
b：标量（偏置）
ŷ：m×1 向量（预测值）
```

**为什么离不开矩阵运算**：

- 数据天然是矩阵（表格 = 样本×特征）
- 预测 = 矩阵乘法，一次算完所有样本（而非循环）
- GPU 擅长并行矩阵运算，这是深度学习算力爆发的基础
