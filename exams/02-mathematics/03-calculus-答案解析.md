## 二、计算题

### 7. 求导

**（1）f(x) = 3x² + 2x + 1**

```
f'(x) = 6x + 2
```

**（2）f(x) = (x² + 1)³（链式法则）**

```
设 u = x² + 1，则 f = u³
f' = 3u² · u' = 3(x²+1)² · 2x = 6x(x²+1)²
```

**答案：（1）6x+2；（2）6x(x²+1)²**

### 8. 链式法则求梯度

```
∂L/∂w = ∂L/∂ŷ × ∂ŷ/∂w

∂L/∂ŷ = 2(ŷ − y) = 2×(1×3 − 2) = 2
∂ŷ/∂w = x = 3

∂L/∂w = 2 × 3 = 6
```

**答案：∂L/∂w = 6**
