## 一、选择题

### 1. B
模型输出概率，是对**不确定性**的建模——"不武断下结论，而是给出相信程度"。

### 2. A
贝叶斯定理：P(A|B) = P(B|A)·P(A) / P(B)。

### 3. B
先验 P(A) 是"看到证据 B 之前" A 本身的概率。

### 4. B
独立事件满足 P(A∩B) = P(A)×P(B)。

### 5. C
经典体检题，阳性后患病概率约 9%（因先验概率太低）。

### 6. A
期望是随机变量的加权平均，描述"平均水平"。

## 二、计算题

### 7. 贝叶斯计算

```
P(垃圾|免费) = P(免费|垃圾)·P(垃圾) / P(免费)
            = 0.6 × 0.2 / 0.3
            = 0.4
```

**答案：P(垃圾邮件 | 含"免费") = 0.4**

### 8. 概率在机器学习中的作用

**为什么预测是概率推断**：现实数据有噪声、模型有不确定性，机器学习输出的是"最可能的答案 + 置信度"，而非绝对真理。

**两个作用举例**：
1. **建模不确定性**：逻辑回归输出概率、Softmax 输出类别分布
2. **推理与更新**：贝叶斯定理用新证据更新信念（朴素贝叶斯分类）
