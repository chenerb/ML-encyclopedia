## 一、高难度选择题

### 1. 答案：**D**

B 对（n=p 时 A·B 定义，结果 m×q），C 对（转置行列互换，Aᵀ 为 n×m）。故选 D。

### 2. 答案：**D**

分母 P(B) 是**证据概率（全概率）**，不能省略——省略只能用于"比较各类别相对大小"时（朴素贝叶斯），但求绝对概率必须算。故选 D。

### 3. 答案：**B**

沿负梯度方向是函数值下降最快的方向。A 错（梯度是向量），C 错（学习率过大震荡/发散），D 错（非凸也可用，只是可能局部最优）。

### 4. 答案：**C**

并非所有损失函数都凸——如结合 Sigmoid 的 MSE 就是非凸的（这正是逻辑回归不用 MSE 的原因）。故选 C。

### 5. 答案：**B**

点积为 0 → 夹角 90°，两向量**垂直（正交）**。

## 二、计算/推导题

### 6. 链式法则

```
设 u = x² + 1，则 f = u²
f'(x) = 2u · u' = 2(x²+1) · 2x = 4x(x²+1)

f'(1) = 4×1×(1+1) = 8
```

**答案：f'(x) = 4x(x²+1)，f'(1) = 8**

### 7. 逻辑回归梯度推导

```
∂L/∂w = ∂L/∂ŷ × ∂ŷ/∂z × ∂z/∂w

∂L/∂ŷ = 2(ŷ − y)
∂ŷ/∂z = σ'(z) = σ(z)(1−σ(z))
∂z/∂w = x

∂L/∂w = 2(ŷ − y) · σ(z)(1−σ(z)) · x
```

**与线性回归梯度的区别**：

- 线性回归：∂L/∂w = 2(ŷ−y)·x（直接，ŷ=wx）
- 逻辑回归（若用 MSE）：多乘了一个 σ'(z) = σ(z)(1−σ(z)) 项

> **关键洞察**：这个多出来的 σ'(z) 在 σ 饱和区（输出接近 0 或 1）趋近 0，导致梯度消失——这正是逻辑回归**不用 MSE 而用交叉熵**的根本原因（交叉熵的梯度不含 σ'，形式简洁为 (σ−y)x）。
