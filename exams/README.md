# 📝 测试卷专区

> **学完即测，输出倒逼输入** —— 这是费曼学习法最关键的闭环。

本目录存放全书配套测试卷，遵循"**每节一测 + 每章一测**"的原则。

---

## 🎯 使用指南

### 正确姿势（强烈建议）

1. **先做题，再看答案**：每份试卷有"题目版"和"答案解析版"两个文件，请务必先做题目版
2. **限时完成**：节末小测建议 20-30 分钟，章节综合卷建议 60-90 分钟
3. **对答案自省**：对照解析，不只改对错，更要**读懂"为什么错"**
4. **定位薄弱点**：解析文件开头的"考点分布表"能帮你快速定位薄弱环节
5. **回炉重读**：错题对应的知识点，回到正文用"费曼自测"重新讲一遍

### 试卷结构

| 类型 | 题量 | 用途 |
|------|------|------|
| **节末小测** | 8-10 题 | 学完一节立即巩固 |
| **章节综合卷** | 15-18 题 | 学完一章串联检验 |
| **挑战卷** | 8-10 题 | 高难度进阶（期末压轴/考研/竞赛难度） |
| **压力面问题** | 10-12 问 | 模拟大厂 ML 岗压力面试 |

### 题型分布

- **选择题**：概念理解 + 易混淆点辨析
- **简单计算题**：直接套用公式
- **中等计算题**：多步推导综合计算
- **证明/推导题**（挑战卷）：推导公式、证明算法性质
- **面试追问**（压力面）：层层追问、质疑挑战、考察临场反应
