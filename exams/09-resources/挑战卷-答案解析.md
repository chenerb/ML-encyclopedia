# 第九章 · 学习资源 挑战卷（答案解析）

## 论述题

### 1. "不用学数学"的评价

**短期上手**：确实可以用框架快速跑通模型，降低门槛。

**长期发展**：不学数学会卡在"调参侠"——看不懂论文、不会诊断问题、无法创新。数学是理解原理、读论文、做研究的基础。

**结论**：可以先"用起来"（框架入门），但想走得远，必须回头补数学。

### 2. 避免"收藏未学习"

**可执行方法**：
1. 设定明确目标（如"三个月掌握传统 ML"）
2. 选一条主线（一本书 + 一门课），而非贪多
3. 拆解成每周任务，配合本书的测试卷检验
4. 输出倒逼：每学完一个概念，写一篇笔记/讲给别人听
5. 定期复盘，砍掉收藏夹里不看的

### 3. 读论文 vs 看二手解读

- **读论文**：需要理解细节、追前沿、做研究时读原论文
- **看博客/视频**：入门、快速了解思想、时间有限时看解读

**判断**：想深入理解/复现/创新 → 读原论文；只想了解大意 → 二手解读。建议核心论文精读原文，其余泛读解读。

### 4. 费曼 vs 打比赛

两者互补：
- **费曼学习法**：倒逼"真正理解"（能讲清才是真懂）
- **打比赛**：倒逼"工程落地"（能跑通才是真会）

**结合**：先费曼讲清原理（检验理解），再打比赛落地（检验工程），循环迭代——理解与实战缺一不可。
