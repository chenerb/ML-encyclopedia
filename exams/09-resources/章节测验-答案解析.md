## 二、简答题

### 11. 零基础学习路径

1. **打基础**：吴恩达《机器学习》+ 西瓜书，学 Python + NumPy + pandas
2. **动手**：李沐《动手学深度学习》（PyTorch）+ Colab 跑代码
3. **实践**：Kaggle 入门赛（Titanic、MNIST）
4. **进阶**：读论文（Transformer、BERT、GPT），追 arXiv
5. **社区**：加入 Datawhale 组队学习，写博客输出

### 12. 五者的作用与组合

- **看书**：搭知识体系（地基）
- **看课**：降低理解门槛（有人带路）
- **写代码**：真正掌握（纸上得来终觉浅）
- **打比赛**：实战检验、工程能力
- **写博客**：输出倒逼输入（费曼学习法）

**组合**：看课入门 → 看书深化 → 写代码巩固 → 打比赛实战 → 写博客沉淀，循环迭代。
