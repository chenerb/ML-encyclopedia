## 二、简答题

### 11. 包含关系与比喻

```
人工智能（AI）⊃ 机器学习（ML）⊃ 深度学习（DL）
```

**比喻**：AI 像"所有烹饪技术"，ML 像"通过试做学厨艺"，DL 像"米其林大厨的复杂技法"——DL 是 ML 里最强大的一类，ML 是 AI 里最主流的一类。

### 12. 技术爆发的条件

**参考答案要点：**

1. **理论/算法突破**：反向传播、ReLU、Transformer 等
2. **数据规模**：互联网产生海量数据（ImageNet、文本）
3. **算力支撑**：GPU 并行计算
4. **工程工具**：框架（PyTorch）降低门槛
5. **产品化"最后一公里"**：ChatGPT 让技术落地为体验

> 深度学习的爆发 = 算法（CNN）+ 数据（ImageNet）+ 算力（GPU）+ 框架 + 产品化，缺一不可。
