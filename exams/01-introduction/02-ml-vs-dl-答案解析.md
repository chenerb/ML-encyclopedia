## 一、选择题

### 1. 答案：**B**

深度学习是机器学习的一个子集（用多层神经网络），机器学习是人工智能的一个子集（从数据中学习）。

### 2. 答案：**B**

最核心区别是**特征提取**：传统 ML 需人工设计特征（如识别猫要设计"耳朵形状"），深度学习自动从原始数据学特征。

### 3. 答案：**B**

海量图片 + 非结构化数据，是深度学习的强项。A 数据量小、C 需可解释、D 样本少，都更适合传统 ML。

### 4. 答案：**C**

结构化表格数据 + 需可解释 → 传统 ML（决策树、逻辑回归）。A、B、D 都是非结构化数据，适合深度学习。

### 5. 答案：**B**

2012 年 AlexNet 在 ImageNet 上大幅领先夺冠，标志着深度学习时代到来。

### 6. 答案：**A**

数据（大数据）、算力（GPU）、算法（ReLU、Dropout 等）三大要素共同成熟。

## 二、简答题

### 7. 厨师比喻

- **人工智能** = 所有"让机器聪明"的技术总称，像"所有烹饪技术"
- **机器学习** = 其中"从数据学习"的方法，像"通过不断试做学厨艺"
- **深度学习** = 机器学习里的"深层神经网络"，像"米其林大厨的复杂技法"，能处理普通厨艺难以应对的复杂菜肴（图像、语言）

### 8. 选型判断依据

**参考答案（答出两条即可）：**

1. **数据类型**：图像/语音/文本等非结构化数据 → 深度学习；结构化表格数据 → 传统 ML
2. **数据量**：数据量小（几千~几万）→ 传统 ML；海量数据 → 深度学习
3. **可解释性需求**：需要强可解释（医疗、信贷）→ 传统 ML；可接受黑盒 → 深度学习
4. **计算资源**：算力受限 → 传统 ML；有 GPU → 深度学习
