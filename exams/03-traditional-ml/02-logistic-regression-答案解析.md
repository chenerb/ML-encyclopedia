## 一、选择题

### 1. 答案：**B**

- **解析**：逻辑回归虽然名字带"回归"，实际是**二分类**算法，输出样本属于"1"类的概率。
- **易错点**：这是全篇最经典的"名不副实"陷阱。要预测连续数值（房价）用线性回归；要判断"是/否"用逻辑回归。

### 2. 答案：**C**

- **解析**：无论输入 z 多大（→1）或多小（→0），Sigmoid 的输出都严格落在 (0, 1) 开区间内，永远不取到 0 或 1 本身。
- **易错点**：tanh 的输出范围才是 (-1, 1)，不要混淆。

### 3. 答案：**B**

- **解析**：σ(0) = 1/(1+e⁰) = 1/(1+1) = 0.5。z=0 对应"完全不确定"，恰好就是分类的默认分界。

### 4. 答案：**B**

- **解析**：Sigmoid 输出压在 (0,1) 后，再套 MSE 会得到**非凸**损失函数，梯度下降容易卡在局部最优。交叉熵损失则保证损失是凸的，便于优化。
- **易错点**：C 是线性回归 MSE 的缺点，不是逻辑回归不用 MSE 的主因；D 错误，MSE 处处可导。

### 5. 答案：**B**

- **解析**：逻辑回归用**交叉熵损失**（对数损失），衡量预测概率与真实标签的差距。
- **易错点**：铰链损失是 SVM 用的；指数损失是 AdaBoost 用的。

### 6. 答案：**B**

- **解析**：阈值从 0.5 提到 0.9，意味着只有"非常确信"才判为"1"类，于是被判为"1"的更少但更准（**精确率↑**），同时漏掉更多真实"1"（**召回率↓**）。
- **易错点**：阈值提高=更保守=宁可漏报不可误报；阈值降低则相反。

## 二、简单计算题

### 7. 计算 σ(1) 和 σ(-1)

```
σ(1)  = 1 / (1 + e⁻¹) = 1 / (1 + 0.368) = 1 / 1.368 ≈ 0.731
σ(-1) = 1 / (1 + e¹)  = 1 / (1 + 2.718) = 1 / 3.718 ≈ 0.269
```

**答案：σ(1) ≈ 0.731，σ(-1) ≈ 0.269**

> 验证：σ(z) + σ(-z) = 1（Sigmoid 的对称性），0.731 + 0.269 = 1 ✓

### 8. 计算 z 与概率

```
z = 2×1 + 3×2 - 4 = 2 + 6 - 4 = 4

P(y=1) = σ(4) = 1 / (1 + e⁻⁴) = 1 / (1 + 0.0183) = 1 / 1.0183 ≈ 0.982
```

**答案：z = 4，P(y=1) ≈ 0.982**

> 说明：z=4 是较强的"证据"，所以概率高达 98.2%，模型几乎确定判为"1"类。

## 三、中等计算题

### 9. 交叉熵损失计算

交叉熵公式（y=1 时简化为 -log ŷ）：

```
（1）ŷ = 0.9：
    Loss = -log(0.9) ≈ 0.105

（2）ŷ = 0.01：
    Loss = -log(0.01) ≈ 4.605
```

**（3）比较与解释：**

预测 0.9（较正确）时损失仅约 0.105；而预测 0.01（几乎完全错误）时损失飙到约 4.605，相差 40 多倍。

**结论**：交叉熵惩罚的是"**自信地犯错**"——模型越确信一个错误答案，惩罚越狠。它鼓励模型在不确定时"诚实地"给出接近 0.5 的概率，而不是盲目自信。

> **易错点**：注意 y=1 时损失简化为 -log(ŷ)，千万别把 (1-y)log(1-ŷ) 那一项也算进去（当 y=1 时该项为 0）。

### 10. 决策边界判断

决策边界是 z = 0 处（对应 P = 0.5）：

```
样本 A = (1, 1)：
  z = 1×1 + 1×1 - 1.5 = 0.5 > 0
  → P > 0.5 → 判为 "1" 类

样本 B = (0, 0)：
  z = 1×0 + 1×0 - 1.5 = -1.5 < 0
  → P < 0.5 → 判为 "0" 类
```

**答案：A 判为 1 类，B 判为 0 类**

> **提示**：决策边界是直线 x₁ + x₂ = 1.5。点 A(1,1) 满足 1+1=2 > 1.5，落在边界正侧；点 B(0,0) 满足 0 < 1.5，落在负侧。
