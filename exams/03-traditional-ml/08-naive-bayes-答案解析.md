## 一、选择题

### 1. 答案：**A**

- **解析**：贝叶斯定理：后验 P(A|B) = 似然 P(B|A) × 先验 P(A) ÷ 证据 P(B)。

### 2. 答案：**B**

- **解析**："朴素"指的是**条件独立性假设**——假设各特征在给定类别下相互独立，从而把联合概率拆成各特征概率的乘积，极大简化计算。

### 3. 答案：**B**

- **解析**：先验 P(A) 是"看到证据 B 之前"，A 本身发生的概率（如"这种病有多罕见"）。看到证据后更新得到的是"后验" P(A|B)。

### 4. 答案：**B**

- **解析**：某个特征在某类里没出现过，概率会算成 0，连乘后整项归零。**拉普拉斯平滑**给每个计数加 1（或一个小的 α），避免零概率。

### 5. 答案：**B**

- **解析**：朴素贝叶斯天然适合高维稀疏的**文本分类**（垃圾邮件过滤、情感分析），虽"朴素"却效果出众。

### 6. 答案：**C**

- **解析**：即使检测 99% 准，由于病**太罕见**（0.1%），阳性后真正患病的概率也只有约 **9%**。这是贝叶斯定理最经典的反直觉结论——不能只看证据强度，还要看"先验"。

## 二、简单计算题

### 7. 贝叶斯定理计算

```
P(垃圾|免费) = P(免费|垃圾)·P(垃圾) / P(免费)
            = 0.6 × 0.2 / 0.3
            = 0.12 / 0.3
            = 0.4
```

**答案：P(垃圾|含"免费") = 0.4**

### 8. 朴素贝叶斯分类（只比较分子）

由于分母 P("免费") 对两类相同，只需比较分子：

```
垃圾类分子 = P(垃圾) × P(免费|垃圾) = 0.3 × 0.8 = 0.24
正常类分子 = P(正常) × P(免费|正常) = 0.7 × 0.1 = 0.07
```

0.24 > 0.07，判为垃圾邮件。

**答案：更可能是垃圾邮件**

> **提示**：朴素贝叶斯只关心"哪类的后验更大"，所以分母（证据概率）可以不算——这正是它高效的原因。

## 三、中等计算题

### 9. 体检题完整推导

**第一步：列出已知**

```
先验：P(患病) = 0.001，P(健康) = 0.999
似然：P(阳性|患病) = 0.99，P(阳性|健康) = 0.01（假阳性率）
```

**第二步：计算证据 P(阳性)（全概率公式）**

```
P(阳性) = P(阳性|患病)·P(患病) + P(阳性|健康)·P(健康)
        = 0.99 × 0.001 + 0.01 × 0.999
        = 0.00099 + 0.00999
        = 0.01098
```

**第三步：贝叶斯定理**

```
P(患病|阳性) = P(阳性|患病)·P(患病) / P(阳性)
            = 0.00099 / 0.01098
            ≈ 0.0902
```

**答案：约 9.0%**

> **关键洞察**：健康人基数巨大（99.9%），哪怕假阳性率只有 1%，产生的假阳性人数（约 999 个）也远超真阳性（99 个）。所以阳性报告里，真正的病人只占约 9%。

### 10. 多特征朴素贝叶斯分类

**垃圾类分子：**

```
P(垃圾) × P(免费|垃圾) × P(中奖|垃圾)
= 0.3 × 0.8 × 0.5 = 0.12
```

**正常类分子：**

```
P(正常) × P(免费|正常) × P(中奖|正常)
= 0.7 × 0.1 × 0.05 = 0.0035
```

**比较：** 0.12 > 0.0035

**答案：更可能是垃圾邮件**

> **易错点**：这里用到"朴素"的条件独立假设——把 P(免费,中奖|垃圾) 拆成 P(免费|垃圾)×P(中奖|垃圾)。现实中"免费"和"中奖"高度相关（常一起出现），独立假设并不严格成立，但朴素贝叶斯依然表现良好，因为它只需要比较**相对大小**。
