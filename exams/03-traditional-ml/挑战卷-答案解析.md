## 一、高难度选择题

### 1. 答案：**B**

- **解析**：**朴素贝叶斯是生成式模型**——它建模联合分布 P(x, y)（先学 P(y) 和 P(x|y)，再用贝叶斯定理求 P(y|x)）。**逻辑回归是判别式模型**——直接建模条件分布 P(y|x)，不关心 x 本身的分布。
- **易错点**：判别式模型"直奔主题"（直接学分类边界），生成式模型"先学数据怎么来的"（能生成样本）。

### 2. 答案：**A**

- **解析**：
  - **交叉熵损失**：`−[y log σ + (1−y)log(1−σ)]`，对任意样本梯度都非零（即使分类正确，也持续"逼近"概率 1 或 0）
  - **铰链损失**：`max(0, 1−y·f(x))`，样本正确且落在间隔外时损失为 0、梯度也为 0
- **易错点**：B 说"都只对错误样本产生梯度"是错的——交叉熵对正确样本也有梯度，只是较小。

### 3. 答案：**A**

- **解析**：正则化**限制模型复杂度**，使模型"欠灵活"，从而**增加偏差**（拟合能力下降），但**降低方差**（不再死记训练数据）。
- **易错点**：总误差 = 偏差² + 方差 + 不可约噪声。正则化是在偏差和方差之间"换"——用一点偏差换掉大量方差。

### 4. 答案：**B**

- **解析**：L1 约束区域是**菱形**（|w₁|+|w₂|≤C），有四个**尖角**在坐标轴上；L2 约束区域是**圆形**，光滑无尖角。损失等高线（椭圆）向外扩张时，更容易先"撞上"L1 菱形的尖角——而尖角恰好在坐标轴上（即某个 w=0），从而产生稀疏解。
- **易错点**：A 是常见误解——稀疏性不是"惩罚力度大"，而是"约束区域的几何形状"决定的。

## 二、复杂计算 / 推导题

### 5. 逻辑回归梯度推导

**第一步：证明 σ'(z) = σ(z)(1−σ(z))**

```
σ(z) = 1/(1+e⁻ᶻ)
σ'(z) = e⁻ᶻ/(1+e⁻ᶻ)² = σ(z)·e⁻ᶻ/(1+e⁻ᶻ)
      = σ(z)·(1 − σ(z))   ✓
```

**第二步：对单个样本求导**

```
J = −[y·log σ + (1−y)·log(1−σ)]

∂J/∂σ = −[y/σ − (1−y)/(1−σ)]

由链式法则：∂J/∂w = ∂J/∂σ · σ' · ∂z/∂w

∂J/∂w = −[y/σ − (1−y)/(1−σ)] · σ(1−σ) · x
      = −[y(1−σ) − (1−y)σ] · x
      = −[y − yσ − σ + yσ] · x
      = −(y − σ) · x
      = (σ − y) · x   ✓
```

**结论：∂J/∂w = (σ(z) − y)·x**

> **洞察**：这个梯度形式极其优美——它等于"预测值与真实值的差"乘以"输入"。梯度下降更新 `w ← w − η(σ−y)x`，和感知机的"错了就改"在形式上惊人相似，但逻辑回归的 (σ−y) 是**连续的概率误差**，而非 0/1 硬误差。

### 6. 正规方程推导

```
J(w) = ‖Xw − y‖² = (Xw − y)ᵀ(Xw − y)

展开：J = wᵀXᵀXw − 2wᵀXᵀy + yᵀy

对 w 求梯度并令其为零：
∇J = 2XᵀXw − 2Xᵀy = 0

⟹ XᵀXw = Xᵀy
⟹ w* = (XᵀX)⁻¹Xᵀy   ✓（前提 XᵀX 可逆）
```

**结论：w\* = (XᵀX)⁻¹Xᵀy**

> **要点**：用到了矩阵求导规则 ∇(wᵀAw) = 2Aw（A 对称）和 ∇(wᵀb) = b。

### 7. 信息增益比

**第一步：分裂信息（Split Info）**

```
SplitInfo = −Σ (|Dᵥ|/|D|)·log₂(|Dᵥ|/|D|)
          = −[ (4/10)log₂(4/10) + (6/10)log₂(6/10) ]
          = −[ 0.4×(−1.322) + 0.6×(−0.737) ]
          = −[ −0.529 − 0.442 ]
          = 0.971
```

**第二步：信息增益比**

```
Gain Ratio = 信息增益 / SplitInfo = 0.125 / 0.971 ≈ 0.129
```

**答案：Split Info ≈ 0.971，Gain Ratio ≈ 0.129**

> **为什么要有信息增益比**：信息增益会偏向"取值多的特征"（如 ID 号切分后每个子节点极纯，增益巨大但毫无泛化意义）。除以 SplitInfo（切分本身的信息量）能惩罚这种"切得太碎"的特征，这正是 C4.5 相对 ID3 的改进。

## 三、证明题

### 8. 证明 SVM 间隔 = 2/‖w‖

**设定**：决策超平面 w·x + b = 0，正类满足 w·x + b ≥ 1，负类满足 w·x + b ≤ −1（经过缩放后）。

**思路**：间隔 = 两个"边缘超平面"（w·x+b=+1 和 w·x+b=−1）之间的距离。

```
任取边缘超平面 w·x+b=1 上一点 x₁，w·x+b=−1 上一点 x₂：
  w·x₁ + b = 1   ...(1)
  w·x₂ + b = −1  ...(2)

(1) − (2)：w·(x₁ − x₂) = 2

两边取范数，由柯西-施瓦茨不等式：
  |w·(x₁−x₂)| ≤ ‖w‖·‖x₁−x₂‖
  ⟹ 2 ≤ ‖w‖·‖x₁−x₂‖
  ⟹ ‖x₁−x₂‖ ≥ 2/‖w‖
```

当 x₁−x₂ 与 w 平行时取等号，此时 ‖x₁−x₂‖ 就是两边缘超平面间的最短距离（即间隔）。

**结论：margin = 2/‖w‖ ✓**

> **推论**：最大化间隔 ⟺ 最小化 ‖w‖（等价于最小化 ‖w‖²/2，这就是 SVM 优化目标里那一项的由来）。

### 9. 证明最小二乘 = 最大似然估计（高斯误差假设下）

**设定**：线性模型 y = w·x + ε，ε ~ N(0, σ²)，即 y | x ~ N(w·x, σ²)。

**似然函数**（样本独立）：

```
L(w) = Πᵢ (1/√(2πσ²)) · exp(−(yᵢ − w·xᵢ)² / (2σ²))
```

**取负对数似然**：

```
−log L(w) = Σᵢ [ (yᵢ − w·xᵢ)² / (2σ²) ] + 常数
          = (1/2σ²) · Σᵢ (yᵢ − w·xᵢ)² + 常数
```

**最大化 L(w) ⟺ 最小化 −log L(w) ⟺ 最小化 Σᵢ (yᵢ − w·xᵢ)²**（常数项和 1/2σ² 不影响最优解位置）。

而 Σᵢ(yᵢ − w·xᵢ)² 正是**均方误差（最小二乘目标）**。

**结论**：在误差服从高斯分布的假设下，最小二乘估计 = 最大似然估计 ✓

> **洞察**：这解释了为什么"平方损失"如此自然——它不是随便选的，而是"假设误差服从高斯分布"下的最优统计推断。同理，若假设误差服从拉普拉斯分布，则会推出 L1 损失（MAE）。

## 四、开放应用题

### 10. 用户流失预测方案（参考答案）

**① 数据预处理**
- 处理缺失值（如优惠券数据缺失用中位数/众数填充）
- 定义流失标签：未来 30 天无登录记为"流失"（标签窗口要与业务对齐）
- 处理类别不平衡：流失用户通常占比少，需重采样或类别加权

**② 特征工程**
- 统计特征：近 7/30 天登录次数、购买金额、评价数
- 趋势特征：登录频率环比变化（下降往往预示流失）
- 行为特征：最近一次购买距今多久（RFM 模型思路）
- 交叉特征：优惠券使用率 = 使用数/领取数

**③ 模型选择**
- 首选 **XGBoost/LightGBM**：表格数据 + 特征组合强，准确率高
- 需可解释时用 **逻辑回归** 或 **决策树**：权重/规则清晰，便于运营理解
- 基线用 **随机森林** 快速验证

**④ 评估指标**
- 流失是"少数类"且漏掉代价高（挽回成本高于误打扰），应优先看 **召回率** 和 **AUC**
- 用 PR 曲线（而非 ROC）更敏感于类别不平衡；报告精确率-召回率权衡，让业务选阈值

**⑤ 上线与迭代**
- 离线验证通过后，A/B 测试：对"高风险用户"推挽回策略，对比流失率
- 持续监控：特征漂移、模型衰减，定期（如每月）用新数据重训
- 闭环：将召回后的用户反馈重新标注，迭代优化

> **评分要点**：能体现"类别不平衡→重召回""可解释性 vs 准确率权衡""上线要 A/B 测试而非直接替换"这三个关键意识，即为高分答案。
