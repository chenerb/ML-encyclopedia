## 一、选择题

### 1. 答案：**B**

- **解析**：决策树通过一系列"是/否"判断，从根到叶逐步缩小范围，和"二十个问题"游戏的思路完全一致。
- **易错点**：C 是感知机/线性分类的做法；D 是 KNN 的做法。

### 2. 答案：**C**

- **解析**：信息熵 H = -Σ pᵢlog₂pᵢ。五五开时 H = -(0.5·log₂0.5 + 0.5·log₂0.5) = -(0.5×(-1) + 0.5×(-1)) = 1，是**最混乱**的状态（二分类下熵的最大值）。
- **易错点**：H=0 表示"完全纯净"（全是一类），别搞反。

### 3. 答案：**B**

- **解析**：信息增益 = 切分前的熵 − 切分后的加权平均熵，衡量"问完这个问题后，混乱程度降低了多少"。增益越大，说明该特征越能"区分"样本。

### 4. 答案：**C**

- **解析**：ID3 用信息增益，C4.5 用信息增益比，**CART 用基尼指数**。sklearn 的 `DecisionTreeClassifier` 默认就是 CART。

### 5. 答案：**B**

- **解析**：决策树容易长得又深又密、把训练样本"记死"，剪枝通过限制深度/样本数或砍掉不重要的分支，防止过拟合。

### 6. 答案：**C**

- **解析**：决策树恰恰**对数据微小变化非常敏感（不稳定）**——数据稍变，树结构可能大变。这正是随机森林要解决的痛点之一。
- **易错点**：A、B、D 都是正确描述，本题选"错误"项，注意审题。

## 二、简单计算题

### 7. 信息熵（6 正 2 负）

```
p(正) = 6/8 = 0.75，p(负) = 2/8 = 0.25

H = -(0.75·log₂0.75 + 0.25·log₂0.25)

log₂0.75 = log₂3 - log₂4 = 1.585 - 2 = -0.415
log₂0.25 = -2

H = -(0.75 × (-0.415) + 0.25 × (-2))
  = -(-0.311 - 0.5)
  = 0.811
```

**答案：H ≈ 0.811**

> 说明：熵小于 1，因为这个节点比"五五开"更"纯"一些（正类占多数）。

### 8. 基尼指数（6 正 2 负）

```
Gini = 1 - (p(正)² + p(负)²)
     = 1 - (0.75² + 0.25²)
     = 1 - (0.5625 + 0.0625)
     = 1 - 0.625
     = 0.375
```

**答案：Gini = 0.375**

> 说明：基尼指数越小越纯，0.375 表示"较纯"（比五五开的 0.5 更小）。

## 三、中等计算题

### 9. 特征 A 的信息增益

**第一步：父节点熵**

```
H(父) = -(0.5·log₂0.5 + 0.5·log₂0.5) = 1
```

**第二步：左子节点熵（3 正 1 负）**

```
p(正)=3/4=0.75, p(负)=1/4=0.25
H(左) = -(0.75·log₂0.75 + 0.25·log₂0.25)
      = -(-0.311 - 0.5) = 0.811
```

**第三步：右子节点熵（2 正 4 负）**

```
p(正)=2/6≈0.333, p(负)=4/6≈0.667
H(右) = -(0.333·log₂0.333 + 0.667·log₂0.667)
      = -(0.333×(-1.585) + 0.667×(-0.585))
      = -(-0.528 - 0.390) = 0.918
```

**第四步：加权平均熵**

```
加权熵 = (4/10)·H(左) + (6/10)·H(右)
       = 0.4×0.811 + 0.6×0.918
       = 0.324 + 0.551 = 0.875
```

**第五步：信息增益**

```
信息增益 = H(父) - 加权熵 = 1 - 0.875 = 0.125
```

**答案：信息增益 = 0.125**

> **提示**：计算时务必用"子节点样本数占比"加权，而不是简单平均两个子节点熵。这是信息增益计算最容易错的一步。

### 10. 过拟合诊断与解决

**（1）现象：过拟合。** 训练集 99% 但测试集 70%，说明模型"记住了"训练数据（包括噪声），泛化能力差。

**（2）解决方案（答出任意两种即可）：**

- **预剪枝**：限制树的最大深度（`max_depth`）、每个节点的最小样本数（`min_samples_split`）、叶子最小样本数（`min_samples_leaf`），让树"别长太大"
- **后剪枝**：先让树长满，再自底向上把增益不大的分支剪掉
- **集成学习**：改用随机森林，用多棵树的投票降低单棵树的方差

> **易错点**：剪枝是"精确"和"泛化"的平衡——剪太多会变成欠拟合（训练集也学不好），剪太少仍会过拟合。
