## 一、选择题

### 1. 答案：**B**

- **解析**：聚类处理的是**没有标签**的数据，让算法自己发现数据的结构，属于**无监督学习**。

### 2. 答案：**B**

- **解析**：K 是预先指定的**簇数量**。K-Means 需要你先告诉它"想分成几堆"。

### 3. 答案：**A**

- **解析**：K-Means 的四字诀是"**反复分组**"：①把每个点分给最近的质心，②重新计算每簇的平均位置作为新质心，③重复直到收敛。

### 4. 答案：**A**

- **解析**：K-Means 对**初始质心**很敏感，不同初始化可能收敛到不同的局部最优。K-Means++ 用更聪明的初始化方式缓解这个问题。

### 5. 答案：**A**

- **解析**：K-Means 基于"到质心的距离"，天然假设簇是**球形**的。对细长形、月牙形、环形簇无能为力（此时 DBSCAN 更合适）。

### 6. 答案：**B**

- **解析**：肘部法则画出"K vs 簇内误差平方和（SSE）"曲线，找误差下降明显变缓的"肘部"拐点，用来选**最优 K**。

## 二、简单计算题

### 7. 质心坐标

```
质心 = (各点坐标的平均值)

x̄ = (1 + 2 + 3) / 3 = 2
ȳ = (1 + 3 + 5) / 3 = 3
```

**答案：质心为 (2, 3)**

### 8. 最近质心分配

```
d(P, A) = √((2−0)² + (1−0)²) = √(4+1) = √5 ≈ 2.24
d(P, B) = √((2−10)² + (1−10)²) = √(64+81) = √145 ≈ 12.04
```

因为 d(P, A) < d(P, B)，所以 P 分配到 A 簇。

**答案：P 分配到质心 A 所在的簇**

## 三、中等计算题

### 9. K-Means 一轮迭代

**（1）分配每个点到最近的质心：**

```
点 (1,1)：d 到 C₁ = √0 = 0；d 到 C₂ = √(16+16) = √32 ≈ 5.66 → C₁
点 (2,1)：d 到 C₁ = √1 = 1；d 到 C₂ = √(9+16) = √25 = 5 → C₁
点 (4,5)：d 到 C₁ = √(9+16) = 5；d 到 C₂ = √(1+0) = 1 → C₂
点 (5,4)：d 到 C₁ = √(16+9) = 5；d 到 C₂ = √(0+1) = 1 → C₂
```

分配结果：C₁ = {(1,1), (2,1)}，C₂ = {(4,5), (5,4)}

**（2）更新质心：**

```
新 C₁ = ((1+2)/2, (1+1)/2) = (1.5, 1)
新 C₂ = ((4+5)/2, (5+4)/2) = (4.5, 4.5)
```

**答案：新 C₁ = (1.5, 1)，新 C₂ = (4.5, 4.5)**

> **提示**：质心是"所属点的平均值"，不是简单取中点。若数据不平衡（簇内点数量不同），加权平均会明显影响质心位置。

### 10. 肘部法则的原理与局限

**原理：**

随着 K 增大，簇内误差平方和（SSE）必然单调下降（K 越大，每簇越"紧"）。但**下降的边际收益递减**：

- K 从 1 到 2、3 时，SSE 大幅下降（找到真正重要的簇结构）
- K 超过"真实簇数"后，继续增大 K 只是"把一个簇硬拆成两个"，SSE 下降变缓

"肘部"就是这条曲线上**下降速度明显变缓的拐点**，它对应着"性价比最高"的 K。

**找不到明显肘部的情况：**

- 数据本身没有清晰的簇结构（均匀分布、连续分布）
- 数据高度重叠，任何 K 的 SSE 都平滑下降
- 此时应换用其他方法（如轮廓系数 Silhouette Score）或结合业务判断 K

> **易错点**：K-Means **一定会**找到 K 个簇，哪怕数据根本没有自然分组。选 K 前要先做探索性分析，别让算法在噪声里强行找结构。
