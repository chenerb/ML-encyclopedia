## 一、选择题

### 1. 答案：**B**

- **解析**：线性回归预测连续值；逻辑回归虽带"回归"二字，实为**分类**。
- **易错点**：逻辑回归是本章最容易"名不副实"的陷阱。

### 2. 答案：**B**

- **解析**：随机森林通过多棵树取平均，显著**降低方差**；代价是可解释性下降。单棵决策树方差大、易过拟合。随机森林是 Bagging，不是 Boosting。

### 3. 答案：**C**

- **解析**：K-Means 处理无标签数据，是无监督学习；其余三个都需要标签，是监督学习。

### 4. 答案：**B**

- **解析**：核技巧把数据隐式映射到高维，处理线性不可分问题。标准化是"必需步骤"但不是"核心工具"。

### 5. 答案：**B**

- **解析**：癌症筛查"宁可错杀、不可漏诊"，要**高召回率**；垃圾邮件过滤则相反，要**高精确率**（别误删重要邮件）。

### 6. 答案：**B**

- **解析**：训练好、测试差，是**过拟合**的典型特征——模型记住了训练数据（含噪声），泛化能力差。

### 7. 答案：**B**

- **解析**：随机森林是 Bagging（并行投票）；XGBoost、AdaBoost 是 Boosting（串行纠错）。

### 8. 答案：**B**

- **解析**："朴素"=特征条件独立假设，把联合概率拆成乘积，大幅简化计算。

### 9. 答案：**B**

- **解析**：K 是簇的数量，需预先指定（可用肘部法则辅助选择）。

### 10. 答案：**A**

- **解析**：KNN 和 SVM 都基于"距离/间隔"，对量纲极敏感，必须标准化。决策树/随机森林对尺度不敏感，朴素贝叶斯也相对稳健。

## 二、简单计算题

### 11. 信息熵（6 正 2 负）

```
p(正) = 0.75，p(负) = 0.25
H = -(0.75·log₂0.75 + 0.25·log₂0.25)
  = -(0.75×(-0.415) + 0.25×(-2))
  = -(-0.311 - 0.5) = 0.811
```

**答案：H ≈ 0.811**

### 12. 欧氏距离

```
d = √((3−0)² + (4−0)²) = √25 = 5
```

**答案：5**

### 13. 精确率与召回率

```
精确率 = TP/(TP+FP) = 80/(80+20) = 0.8
召回率 = TP/(TP+FN) = 80/(80+20) = 0.8
```

**答案：精确率 0.8，召回率 0.8**

### 14. σ(0)

```
σ(0) = 1/(1+e⁰) = 1/2 = 0.5
```

**答案：0.5**

## 三、中等计算题

### 15. 最小二乘（(1,2),(2,4),(3,5)）

```
x̄ = 2，ȳ = (2+4+5)/3 = 11/3

分子 Σ(xᵢ-x̄)(yᵢ-ȳ) = (1-2)(2-11/3) + 0 + (3-2)(5-11/3)
                    = 5/3 + 4/3 = 3
分母 Σ(xᵢ-x̄)² = 1 + 0 + 1 = 2

w = 3/2 = 1.5
b = ȳ - w·x̄ = 11/3 - 3 = 2/3
```

**答案：y = 1.5x + 2/3**

### 16. 信息增益

```
H(父) = 1
H(左) = 0.811（3正1负）
H(右) = 0.918（2正4负）

加权熵 = (4/10)×0.811 + (6/10)×0.918 = 0.875
信息增益 = 1 - 0.875 = 0.125
```

**答案：0.125**

### 17. 贝叶斯定理（体检题）

```
P(患病|阳性) = P(阳性|患病)·P(患病) / P(阳性)

分子 = 0.99 × 0.001 = 0.00099
分母 = 0.99×0.001 + 0.01×0.999 = 0.01098

P = 0.00099 / 0.01098 ≈ 9.0%
```

**答案：约 9.0%**

## 四、简答题

### 18. 算法选型

**需要可解释时：推荐决策树（或逻辑回归）**

- **决策树**：可画出清晰的"if-then"规则（如"收入<5000 且 负债>50% → 高风险"），监管和业务方都能看懂；无需标准化，开箱即用
- **逻辑回归**：权重直接表示"每个特征对违约风险的影响方向和大小"，可解释性强，且输出概率便于设定风险阈值

**放弃可解释性、追求最高准确率：改用集成方法**

- **随机森林**：多棵树投票，准确率显著提升，可解释性下降，但可用"特征重要性"部分弥补
- **XGBoost / LightGBM**：Boosting 方法，是结构化表格数据竞赛的"王者"，准确率通常最高，但基本是黑盒

> **点评**：这是典型的"可解释性 vs 准确率"权衡题。金融风控因监管要求，往往优先选决策树/逻辑回归；若做营销预测等低风险场景，则可上 XGBoost 追求极致准确率。
