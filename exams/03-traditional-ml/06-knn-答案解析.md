## 一、选择题

### 1. 答案：**B**

- **解析**：KNN 只看"离样本最近的 K 个邻居是谁"，多数投票决定类别——"近朱者赤，近墨者黑"。

### 2. 答案：**B**

- **解析**：KNN 训练时只是"记下"所有数据，不做任何学习；真正的计算（算距离、找邻居）都在**预测时**才做，所以叫"懒惰学习"。

### 3. 答案：**B**

- **解析**：K=1 时只看最近的一个邻居，一个噪声点或异常值就能完全决定分类结果，极易过拟合。

### 4. 答案：**B**

- **解析**：KNN 完全基于距离。若某特征量纲很大（如收入以"元"计，是几万），会主导距离计算；标准化让所有特征"公平"参与。

### 5. 答案：**C**

- **解析**：d = √((4−1)² + (6−2)²) = √(9+16) = √25 = 5。这是个 3-4-5 直角三角形。

### 6. 答案：**B**

- **解析**：维度升高后，所有点之间的距离趋于接近，"最近邻"和"最远邻"差别变小，距离失去区分度，KNN 性能急剧下降。这就是"维度灾难"。

## 二、简单计算题

### 7. 欧氏距离

```
d = √((3−0)² + (4−0)²) = √(9 + 16) = √25 = 5
```

**答案：5**

### 8. 曼哈顿距离

```
d = |3−0| + |4−0| = 3 + 4 = 7
```

**答案：7**

**区别**：欧氏距离是"直线距离"（像飞鸟直接飞过去）；曼哈顿距离是"沿网格走直角"的距离（像在城市街区里只能横竖走）。两者分别对应 L2 和 L1 范数。

## 三、中等计算题

### 9. KNN 完整分类流程

**第一步：计算 P 到所有训练样本的欧氏距离**

```
d(P, A) = √((3−1)² + (3−1)²) = √8  ≈ 2.83
d(P, B) = √((3−2)² + (3−2)²) = √2  ≈ 1.41
d(P, C) = √((3−5)² + (3−5)²) = √8  ≈ 2.83
d(P, D) = √((3−6)² + (3−6)²) = √18 ≈ 4.24
```

**第二步：按距离升序排列**

```
B(猫, 1.41) < A(猫, 2.83) = C(狗, 2.83) < D(狗, 4.24)
```

**第三步：取最近的 K=3 个邻居**

```
B(猫)、A(猫)、C(狗)
```

**第四步：投票**

```
猫 2 票，狗 1 票 → 判为"猫"
```

**答案：P 被分类为"猫"**

> **易错点**：A 和 C 距离相同（都是 √8），这里恰好不影响结果（因为猫已 2 票）。但在实际中遇到"距离并列"要小心处理；若 K=3 时第 3、4 名距离相同，结果可能不确定。

### 10. K 值的选择

**K 太小（如 K=1）：**
- 只看最近一个邻居，极易被噪声点、异常值带偏 → **过拟合**
- 决策边界过于曲折

**K 太大（如 K=N）：**
- 几乎看全部样本，预测趋近于"多数类"，边界过于平滑 → **欠拟合**
- 甚至被类别不平衡的多数类"淹没"

**为什么通常选奇数：**
- 二分类中，偶数 K 可能出现"3:3 平票"的尴尬局面；奇数 K 保证投票一定能分出胜负。

**实际做法**：用交叉验证画"K vs 误差"曲线，找误差最低的 K（通常取奇数）。
