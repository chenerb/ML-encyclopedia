## 一、选择题

### 1. 答案：**B**

- **解析**：1886 年，英国统计学家**高尔顿**（Francis Galton，达尔文的表弟）研究遗传学时发现：高个子父母的子女平均身高虽高于常人，却比父母更接近总体平均水平；矮个子父母的子女也向均值靠拢。他把这种现象称为"回归到平庸"（regression to mediocrity），这就是"回归"一词的由来。
- **易错点**：高斯和勒让德都与**最小二乘法**有关，但不是"回归"一词的提出者；皮尔逊研究的是相关系数。

### 2. 答案：**C**

- **解析**：最小二乘法的目标是最小化**残差平方和**，即 `Σ(yᵢ - ŷᵢ)²`，也称 SSE（Sum of Squared Errors）或 RSS。MSE 就是 SSE 除以样本数 n。
- **易错点**：A 选项"残差之和"会被正负误差抵消（高估 10 万 + 低估 10 万 = 0），无法反映真实误差；B 选项（MAE 的思想）虽可避免抵消，但不可导、优化不便；D 选项不是主流损失。

### 3. 答案：**B**

- **解析**：w = 0 表示拟合出的直线是水平的，即模型认为 x 的变化**不会**引起 y 的线性变化。这只能说明"在**线性**模型下两者无关"，不代表一定有问题——可能两者本身就是非线性关系（如抛物线），需要换模型或加特征。
- **易错点**：A 是常见误解——w = 0 是合法的拟合结果；C、D 都过度推断。

### 4. 答案：**B**

- **解析**：解析解需要对 `XᵀX` 求逆，因此要求 **XᵀX 可逆**（等价于 X 列满秩、特征之间不存在完全的多重共线性）。
- **易错点**：A 不是充分条件（样本多但特征共线仍不可逆）；C 标准化不影响可逆性；D 是统计推断（如做假设检验）的假设，不是求解的前提。

### 5. 答案：**B**

- **解析**：R²（决定系数）表示模型解释的目标变量**方差比例**，公式 `R² = 1 - SSE/SST`。R² = 0.9 表示模型解释了 90% 的方差。
- **易错点**：R² 不是"准确率"（分类指标才用准确率）；也不是"误差 10%"；在一元线性回归中 R² 恰好等于相关系数 r 的平方（不是 r 本身）。

### 6. 答案：**B**

- **解析**：MSE 对误差做**平方**，异常值的大误差会被平方放大，因此对离群点最敏感。一个误差为 10 的离群点，在 MSE 里贡献 100，远超其他点。
- **易错点**：MAE 用绝对值，对异常值相对稳健；这也是为什么"抗噪"场景常改用 MAE 或 Huber 损失。

## 二、简单计算题

### 7. 求 (1,3)、(2,5)、(3,7) 的回归直线

**步骤：**

```
x̄ = (1+2+3)/3 = 2
ȳ = (3+5+7)/3 = 5

w = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²
  = [(1-2)(3-5) + (2-2)(5-5) + (3-2)(7-5)] / [(1-2)² + (2-2)² + (3-2)²]
  = [(-1)(-2) + 0 + (1)(2)] / [1 + 0 + 1]
  = [2 + 0 + 2] / 2
  = 4 / 2 = 2

b = ȳ - w·x̄ = 5 - 2×2 = 1
```

**答案：y = 2x + 1**

> 验证：三个点恰好都在直线 y = 2x + 1 上，所以这是一条完美拟合的直线（MSE = 0）。

### 8. 计算 MSE

```
误差 eᵢ = yᵢ - ŷᵢ：
  e₁ = 3 - 2.8 = 0.2
  e₂ = 5 - 5.1 = -0.1
  e₃ = 7 - 6.9 = 0.1

MSE = (0.2² + (-0.1)² + 0.1²) / 3
    = (0.04 + 0.01 + 0.01) / 3
    = 0.06 / 3
    = 0.02
```

**答案：MSE = 0.02**

## 三、中等计算题

### 9. 求 (1,2)、(2,4)、(3,5) 的回归直线并预测

**（1）求回归方程：**

```
x̄ = 2，ȳ = (2+4+5)/3 = 11/3

分子 Σ(xᵢ-x̄)(yᵢ-ȳ)：
  (1-2)(2-11/3) = (-1)(-5/3) = 5/3
  (2-2)(4-11/3) = 0
  (3-2)(5-11/3) = (1)(4/3) = 4/3
  合计 = 5/3 + 4/3 = 3

分母 Σ(xᵢ-x̄)²：
  (1-2)² + (2-2)² + (3-2)² = 1 + 0 + 1 = 2

w = 3/2 = 1.5

b = ȳ - w·x̄ = 11/3 - (3/2)×2 = 11/3 - 3 = 2/3
```

**答案：y = 1.5x + 2/3**

**（2）预测 x = 4：**

```
y = 1.5×4 + 2/3 = 6 + 2/3 = 20/3 ≈ 6.67
```

**答案：预测值 ≈ 6.67**

> **注意**：本题数据不在一条直线上（第三个点 (3,5) 偏离了 y=2x），所以这是"真正"的最小二乘拟合，预测值 6.67 不同于任何直接外推的整数。

### 10. 为什么用平方和而非残差和？

**参考答案（至少答出两点）：**

**角度一：正负抵消问题。** 残差有正有负，直接相加会互相抵消。例如"高估 10"和"低估 10"相加得 0，会让损失函数误以为"没有误差"。平方后所有误差都变成非负数，能真实反映误差的大小。

**角度二：大误差惩罚更重。** 平方放大了大误差的代价（误差 10 的平方是 100，误差 1 的平方是 1），促使模型优先消除大的偏差，得到整体更均衡的拟合。

**角度三（加分项）：数学性质好。** 平方函数连续可导，且最小二乘有漂亮的解析解 w = (XᵀX)⁻¹Xᵀy；从概率角度看，最小化平方误差等价于在"误差服从高斯分布"假设下的**最大似然估计**。

> **易错点提示**：很多同学只答"避免抵消"而漏掉"大误差惩罚"和"可导性/概率解释"。完整理解平方损失的合理性，是理解后续逻辑回归为什么**改用交叉熵**的关键铺垫。
