## 一、选择题

### 1. 答案：**B**

- **解析**：SVM 不满足于"能分开"，而是追求**间隔最大**的超平面——让边界离两类数据都尽可能远，从而对新数据最稳健。
- **易错点**：A 是"随便分类"，任何能分开的线都可以，但 SVM 要的是"最好"的那条。

### 2. 答案：**B**

- **解析**：支持向量是**离超平面最近、恰好"撑起"间隔**的那几个点。删除远处的普通点不影响边界，但移动支持向量会立即改变边界。

### 3. 答案：**B**

- **解析**：核技巧把数据隐式映射到高维空间，在那里找线性边界，再投影回原空间变成曲线边界，从而处理**线性不可分**数据。
- **易错点**：核技巧不会加速训练（往往更慢），也不自动做特征选择。

### 4. 答案：**B**

- **解析**：C 是"错误容忍度"的倒数。**C 大 = 惩罚重 = 更严格**，尽量分对所有点（包括噪声），容易过拟合；C 小 = 更宽松，容忍错误，间隔更宽、泛化更好。

### 5. 答案：**B**

- **解析**：SVM 基于距离和间隔，对**特征量纲极其敏感**。量纲大的特征会"主导"距离计算，让间隔完全失真，所以**必须先标准化**。

### 6. 答案：**B**

- **解析**：gamma 控制 RBF 核的"影响半径"。**gamma 越大**，每个支持向量的影响范围越小，决策边界越曲折复杂，越容易过拟合；gamma 越小，边界越平滑。

## 二、简单计算题

### 7. 判断样本在超平面的哪一侧

```
点 A = (2, 2)：w·x + b = 1×2 + 1×2 - 3 = 1 > 0 → 正侧
点 B = (1, 1)：w·x + b = 1×1 + 1×1 - 3 = -1 < 0 → 负侧
```

**答案：A 在正侧（预测为 +1 类），B 在负侧（预测为 -1 类）**

### 8. 点到超平面的距离

```
距离 = |w·x + b| / ‖w‖

点 A 的 w·x + b = 1（第 7 题已算）
‖w‖ = √(1² + 1²) = √2

距离 = |1| / √2 = √2 / 2 ≈ 0.707
```

**答案：距离 ≈ 0.707**

## 三、中等计算题

### 9. 间隔 margin 的计算

**（1）间隔大小：**

```
‖w‖ = √(1² + 1²) = √2

margin = 2 / ‖w‖ = 2 / √2 = √2 ≈ 1.414
```

**（2）点 A 与间隔的关系：**

```
点 A 到决策超平面的距离 = √2/2 ≈ 0.707（第 8 题）

边缘超平面到决策超平面的距离 = margin/2 = √2/2 ≈ 0.707
```

**结论**：点 A 到超平面的距离恰好等于间隔的一半，说明**点 A 正好落在边缘超平面 x₁+x₂−3=+1 上，即点 A 是一个"支持向量"**。

> 验证：A = (2,2) 代入边缘超平面 x₁+x₂−3 = 2+2−3 = 1 ✓，确实落在正侧边缘上。

### 10. 参数 C 的权衡

**C = 0.01（很小）：**

- 对错误分类的惩罚很轻，**容忍大量错误**
- 分类间隔更宽，决策边界更"平缓"
- 倾向于**欠拟合**（可能连训练集都分不好），但泛化潜力好

**C = 1000（很大）：**

- 对错误分类的惩罚极重，**几乎不允许任何错误**
- 分类间隔变窄，边界努力绕过每一个点（包括噪声点）
- 倾向于**过拟合**（训练集完美，测试集可能差）

**结论**：C 是"拟合训练集"和"保持泛化"之间的权衡旋钮，需要用交叉验证选一个合适的中间值。

> **易错点**：C 的作用方向和直觉相反——**C 越大越"严格"（越容易过拟合）**，不是"越大越宽松"。
