# GRU网络 · 节末小测（答案解析）

## 一、选择题

### 1. A
GRU 是 LSTM 的精简版（2014 年提出）。

### 2. A
两个门：更新门 z、重置门 r。

### 3. A
GRU 参数少约 1/4，训练更快。

### 4. A
更新门决定保留多少旧记忆（(1−z) 决定写入多少新信息）。

### 5. A
GRU 无独立细胞状态，h_t 兼任，结构更简洁。

## 二、简答题

### 6. 精简账本比喻

LSTM 像"三本账 + 三个管理员"（遗忘门、输入门、输出门 + 独立细胞状态）。GRU 合并成"一本账 + 两条规矩"：更新门（旧记录留多少）、重置门（写新账时翻不翻旧账）。少一个门、少一套参数，效果接近。

### 7. GRU 更划算的场景

- 资源受限（移动端、边缘设备）
- 小数据集（参数少不易过拟合）
- 需要快速训练迭代时

> 大模型、海量数据下 LSTM 表达力略强，但多数场景 GRU 性价比更高。
