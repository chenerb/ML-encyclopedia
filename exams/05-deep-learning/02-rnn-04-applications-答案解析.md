### 2. C

## 二、简答题

### 6. 翻译官比喻

翻译官做同传时"边听边记"：听到"尽管……"，先记住这是让步；听到"但是……"，知道转折来了；听到"充满信心"，结合前面翻出完整意思。RNN 正是"边处理边记前文"，能捕捉语言中的顺序和上下文。

### 7. 三个应用

- **机器翻译**：序列 = 源语言词序列 → 目标语言词序列
- **语音识别**：序列 = 音频帧序列 → 文字序列
- **文本生成**：序列 = 已生成的词序列 → 下一个词
