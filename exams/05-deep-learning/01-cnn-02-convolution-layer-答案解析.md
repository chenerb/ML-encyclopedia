# 卷积层 · 节末小测（答案解析）

## 一、选择题

### 1. A
卷积 = 核在图上滑动 + 对应位置相乘求和。

### 2. A
不同数值的核检测不同特征（如竖直边缘核、水平边缘核）。

### 3. A
步长通常取 1（配合 padding 保持尺寸）。

### 4. A
(32−5)/1 + 1 = 28，输出 28×28。

### 5. A
多核 = 多种特征探测器，一层输出多个特征图。

## 二、计算/简答

### 6. 卷积核 = 印章

卷积核的数值像"印章的图案"，滑动比对（点乘）时，图案对得上（该位置有对应特征）输出值就大。所以：
- 刻"竖纹"的印章 → 检测竖直边缘
- 刻"横纹"的印章 → 检测水平边缘

不同数值 = 不同图案 = 检测不同特征。

### 7. 输出尺寸

```
公式：输出 = (输入 − 核大小 + 2×填充) / 步长 + 1
输出 = (5 − 3 + 0) / 1 + 1 = 3
```

**答案：输出 3×3**
