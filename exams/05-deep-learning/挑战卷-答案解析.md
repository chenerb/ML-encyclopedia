## 二、推导/计算题

### 5. 输出尺寸

**第一组（卷积→池化）：**

```
卷积：输出 = (32 − 3 + 2×1)/1 + 1 = 32（padding 保持尺寸）
池化：32/2 = 16
→ 16×16
```

**第二组：**

```
卷积：(16−3+2)/1+1 = 16
池化：16/2 = 8
→ 8×8
```

**答案：第一组后 16×16，第二组后 8×8**

### 6. 注意力 O(n²) 复杂度

自注意力要计算每个词与所有词的关系：Q·Kᵀ 得到 n×n 的相似度矩阵，复杂度 O(n²)。

**长序列问题**：序列越长，计算和内存爆炸（如 10 万 token 的文档）。

**解决思路**：
- 稀疏注意力（只关注局部 + 少量全局）
- 滑动窗口 / 分块注意力（Longformer）
- 线性注意力近似
- FlashAttention（高效实现）

## 三、开放题

### 7. 文生图系统选型

**推荐：扩散模型（Stable Diffusion 类）**

**理由**：
- 生成质量最高（远超 GAN、VAE）
- 训练稳定（无 GAN 的对抗博弈）
- 天然支持条件生成（文字引导去噪）

**架构简述**：
```
文字编码器（CLIP）→ 文字嵌入
   ↓ 引导
随机噪声 → [扩散模型逐步去噪 × N 步] → 生成图像
```

> 评分要点：能说出"扩散模型质量高、训练稳、支持条件生成"，并给出"文字编码 + 条件去噪"的大致架构，即为高分。
