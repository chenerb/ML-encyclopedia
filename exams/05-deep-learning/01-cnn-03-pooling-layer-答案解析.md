# 池化层 · 节末小测（答案解析）

## 一、选择题

### 1. C
池化的作用是降采样、增鲁棒、扩感受野，**不负责提取特征**（提取特征是卷积层的活）。

### 2. A
最大池化最常用（保留最强特征信号）。

### 3. B
池化层无参数，只做固定的取最大/平均。

### 4. B

### 5. A

## 二、简答题

### 6. 最大池化更常用的原因

特征图里的大数值代表"某特征强烈存在"。取最大值 = 保留最显著的特征信号，丢弃弱的和位置细节，符合"抓大放小"。

### 7. 池化 vs 卷积

- **卷积层**：有可学习参数（卷积核），负责**提取特征**
- **池化层**：无参数，只做降采样（取最大/平均），负责**浓缩特征、减计算**

两者配合：卷积提取 → 池化浓缩，交替堆叠构成 CNN 主干。
